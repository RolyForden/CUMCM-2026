# 2026 国赛 C 题公开解法对比记录

检索时间：2026-09-13。当前仍处于竞赛期，公开内容变化很快；以下只记录当时能核对到的材料。

## 一句话结论

当前论文的强项不是模型名更复杂，而是信息边界更严格、跨日状态更真实、结果有独立核算。公开方案最值得借鉴的是图表表达和风险模型思路，不宜直接照搬其数值。

## 公开路线概览

| 路线 | 主要做法 | 可信度与用途 |
|---|---|---|
| 线性规划基线 | 144 个十分钟时段，功率平衡、SOC、功率上限、效率、弃光 | 高；各来源共识 |
| 日内滚动优化 | 0/6/12/18 点更新光伏预报，只重算未执行时段 | 高；与当前论文主线一致 |
| 随机/鲁棒优化 | SAA 场景树、CVaR、预算不确定集 | 中；有公开复现，但口径与题面基线不同 |
| 强化学习 | 用于学习安全裕量或实时修正 | 低到中；多为计划或建议，缺少同口径正式结果 |
| 简单网络文章 | LP、MPC、随机优化的概念性介绍 | 低；适合查关键词，不适合核对数字 |

## 模型差异

| 对比点 | 当前论文 | 主要公开复现 | 影响 |
|---|---|---|---|
| 问题一 | 确定性 LP；周期库存；另用显式互斥 MILP 对拍 | 同为 LP/MILP | 总量与费用一致，基础模型互相印证 |
| 问题二预测 | 负荷和光伏均用严格因果的 D-7 同刻预测；比较同星期日平均与分位保守量 | 当日负荷视为已知；光伏每天使用附件 1 典型日预测 | 两者信息集不同，全年费用不可直接排名 |
| 跨日 SOC | 实际 SOC 连续传递；7 天滚动视野，只执行首日 | 多数公开复现每天强制回到 6000 kWh，逐日独立求解 | 当前论文更符合跨日运行，也获得更大调度自由度 |
| 问题三 | 0/6/12/18 点滚动；已执行时段锁定；按相邻版本现金流结算 | 同为四时点滚动，另有计划跟踪和实时平衡两种执行规则 | 主线一致，执行器与结算细节不同 |
| 预报时点结论 | 6:00、12:00 有明显价值；18:00 边际收益近零且略有反作用 | 公开复现给出的边际价值也是 6:00、12:00 明显、18:00 约为零 | 定性结论高度一致 |
| 问题四价格 | 预测价只用于决策，真实价只用于执行和结算；另设完美信息下界 | 主要公开复现直接把附件 4 全年真实价格视为计划时已知 | 当前论文因果口径更严格；两者结果不宜直接比较 |
| 验证 | 逐槽物理复算、账本复算、工作簿回读、替代模型、消融、完美信息下界 | KKT/强对偶、CBC、DP、残差、规则策略、SAA/CVaR/鲁棒对比 | 两边验证互补；当前论文对正式文件链条审计更完整 |
| 未纳入因素 | 不计电池寿命，不做 SAA/CVaR 正式策略 | 有来源加入寿命成本、场景树、CVaR 和 MPC 实时闭环 | 可作展望，若无正式重算不应写成本文成果 |

## 结果对比

下表的“公开复现”指可核对到完整数字的 GitHub 方案。差额为“当前论文减公开复现”。

| 问题 | 当前论文/元 | 公开复现/元 | 差额/元 | 说明 |
|---|---:|---:|---:|---|
| 1 | 35,126.95 | 35,126.95 | 约 0 | 总购电量也同为 59,482.70 kWh |
| 2 | 16,886,077.67 | 18,092,018.06 | -1,205,940.39 | D-7 + 7 天视野 + 跨日 SOC，对方为典型日光伏 + 每日闭环 |
| 3 | 15,805,751.77 | 16,970,919.00 | -1,165,167.23 | 预测、执行器、SOC 终端口径不同 |
| 4-2 | 17,743,324.88 | 19,281,482.14 | -1,538,157.26 | 当前论文预测价格，对方直接使用真实波动价格；不能据此判断优劣 |
| 4-3 | 16,606,095.44 | 17,702,310.51 | -1,096,215.07 | 同上，且两边日内执行细节不同 |

紧急购电量也较低：问题二当前为 1,199,863.45 kWh，公开复现为 1,373,687.30 kWh；问题三当前为 809,227.14 kWh，公开复现约 976,388.10 kWh。主要原因仍是预测与跨日调度口径不同。

注意：费用低不等于模型一定更好。若决策时使用了更多未来信息、期末 SOC 更宽松或结算规则不同，费用会自然下降。正式比较必须先统一信息集和边界条件。

## 第一问的时间标签差异

另一份独立 GitHub 复现把附件时间当作十分钟区间的右端点，因此将附件 `10:10` 对应到 `10:00-10:10`。它与当前论文的全天费用、全天购电量和四小时分块结果完全一致，但部分指定十分钟数值不同：

| 时段 | 当前论文/kWh | 右端点复现/kWh |
|---|---:|---:|
| 12:00-12:10 | 486.403 | 480.412 |
| 16:00-16:10 | 394.931 | 445.432 |
| 18:00-18:10 | 636.983 | 531.894 |

这不是优化器差异，而是题面附件与结果模板的时间标签不自洽造成的一槽偏移。当前论文已明确采用“模板按位置对应、不平移”的冻结口径；提交前不宜临时改口径，但答辩或说明中应能解释这一点。

## 值得记录的美观图表类型

公开完整复现使用的图表较丰富，以下类型最适合本题：

| 图表类型 | 表达内容 | 对当前论文的价值 |
|---|---|---|
| 三联时序图 | 电价；负荷/光伏；购电/充放电/SOC | 高：一张图讲清问题一的物理机制 |
| 正负填充调度图 | 购电、充电画在零轴两侧，叠加净负荷与 SOC | 高：比单纯表格更直观 |
| 典型日四层对照图 | 预测光伏与实际光伏；初始与调整购电；紧急购电面积；SOC | 高：最能解释问题三为何省钱 |
| 费用构成堆叠柱图 | 正常合同费、调整费、紧急购电费，按月或按策略分组 | 高：当前问题二缺少直观费用结构图 |
| 逐日曲线 + 逐月柱图 | 上图看异常日，下图看季节规律 | 中高：兼顾细节与总览 |
| 预报信息阶梯柱图 | 典型日、每日 0 点、加入 6/12/18 点后的费用 | 中高：与当前消融表相配 |
| 保守裕量—费用曲线 | 不同光伏折减或分位数对应总费用 | 中：当前已有表，可用曲线展示 U 形权衡 |
| 风险—成本散点图 | 期望费用与 CVaR/最差日形成帕累托前沿 | 中：只有真正完成风险模型后才能使用 |
| 策略对比双柱图 | 一侧总费用，一侧紧急购电量 | 中：适合多模型总览 |
| 寿命成本双图 | 能量费/寿命费与等效循环寿命 | 低：当前未建寿命模型，只适合展望 |

当前论文已有四类图：LP/MILP 散点与 SOC 对拍、参数敏感性横条与箱线图、问题三月度折线与时点消融柱图、问题四月度分组柱图。优点是验证性强；不足是缺少“典型日从输入到动作再到 SOC”的解释型图，且图内英文标签与中文正文风格不统一。

## 若只补三张图

1. **问题二月度费用构成堆叠柱图**：正常合同费与紧急购电费分色，直接支撑 27.8% 的费用结构结论。
2. **问题三典型日四层对照图**：预测/实际光伏、初始/调整购电、紧急购电、SOC 同轴对齐。
3. **问题四预测价—真实价对照图**：选一个典型日或给出月度 MAE，同时标明“预测价决策、真实价结算”。这是当前论文区别于多数公开方案的核心证据。

若页数紧，不建议再加总费用柱图；现有表格和月度图已经足够。所有新增图必须由正式产物生成，数字不能手填。

## 可借鉴与不可直接借鉴

可借鉴：图表布局、费用分解、风险—成本评价思想、时点价值的表达方式、题意陷阱清单。

不可直接借鉴：公开方案的全年费用、每天回到 6000 kWh 的假设、把附件 4 真实未来价格直接用于优化、把负荷默认为决策时已知，以及没有同口径重算支撑的 SAA/CVaR/寿命结论。

## 最终判断

- 当前论文无需因公开方案出现而改主模型。
- 最有价值的外部启发是补强解释型可视化，不是堆叠更复杂的模型名。
- 若赛后继续改进，优先做统一信息集下的 SAA/CVaR 对照；若赛前只做收口，保持现有正式结果不变更稳妥。
