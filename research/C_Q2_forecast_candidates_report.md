# 第二问历史预测候选阶段报告

## 结论

已经实现两个严格因果的候选接口：七天前同一时刻、最近四个同星期日衰减平均。它们只读取决策时刻前已经观测到的负荷和实际光伏，并为当天144槽生成点预测。D010确定的一月冷启动也已实现。

昨天同一时刻的直接复制暂未作为完整候选：按时间方案A，每天计划的末槽位于次日00:00至00:10，在当天00:00制定计划时，其“昨天同刻”实际值也要到00:10才观测完整。测试要求这种情况直接报错，避免偷看未来。

## 验证

- `python src/q2_forecast_tests.py`：8/8通过。
- 覆盖144槽完整性、历史观测截止时间、未来数据拒绝、七天前基线和同星期衰减基线。
- 机器结果：`experiments/q2_forecast_candidate_results.json`。

## 边界

本报告尚未选择1月8日以后的最终预测器。选择最终方法前，应在严格按时间推进的验证中比较预测误差和实际运行费用。

D010裁决后，冷启动规则已经明确：1月1日完整使用附件1先验；1月2日至7日逐槽使用已经观测到的历史平均，尚未观测或没有历史的槽回退附件1。测试确认1月2日00:00只能使用前一天已经结束的143槽，末槽继续使用先验。

## 一月只读比较

在2025年1月15日至30日做了16天顺序预测比较，每种方法共2304个槽位：

- 七天前同刻：负荷 MAE 142.05 kW，光伏 MAE 136.10 kW。
- 同星期日衰减平均：负荷 MAE 118.19 kW，光伏 MAE 138.07 kW。

同星期日平均在负荷上更好，七天前同刻在光伏上略好。该结果只评价预测误差，还不能代替按实际购电总费用选择正式策略。机器结果为 `experiments/q2_forecast_candidate_evaluation.json`。
