# 1. 每道题的核心判断

## A 题：药材的烘干问题

**本质上要解决什么**

建立圆柱药材径向的非稳态传热-传质偏微分方程，先处理固定几何和常/变物性，再根据含水阈值求终止时间，最后引入半径收缩的移动边界。

**推荐的初步模型路线**

在长径比较大的假设下建立一维轴对称径向模型，用有限体积或守恒型有限差分离散，边界采用中心对称和表面对流换热/传质；问题 2-3 使用温度、水分相关物性；问题 4 用归一化坐标或 ALE 思路处理收缩边界。

**核心判断**

- 题意理解难度高：必须补全 PDE、初边值、单位和几何简化，任一处写错都会贯穿四问。
- 数据格式清晰且很小，处理不难；但输入只给烘房边界和半径，不提供内部观测真值，实证验证很弱。
- 四个子问题逻辑链非常自然：常参数、变参数、阈值时间、收缩边界。
- 数学深度和论文上限高，可比较固定/变物性、固定/收缩几何、不同网格和步长。
- 编程难点不是输出数值，而是离散中心奇点、非线性系数、对流边界、移动边界与长时间稳定性。
- 参数调试本身不多，但网格/时步收敛和物理一致性检查成本高。
- 领域依赖度高：需熟悉扩散方程、圆柱坐标系和传热传质边界。
- 没有常规机器学习数据泄漏问题，但存在“数值算出了却无法验证是否接近真实”的核心风险。
- 可做网格独立性、时步敏感性、质量守恒、参数摄动和两类经验公式对比；图表可用时空云图、径向曲线、收缩轨迹，质量高。
- Agent 可并行做 PDE 推导、数值实现和独立校验；但几个 Agent 对错误边界条件一致同意不等于真验证。
- 两人宜一人负责物理推导与公式核对，一人负责代码、收敛和图表。

**A. 最快可信 baseline**：约 3-5 小时可得到问题 1 的一维差分解；加上网格收敛和物理界检查后，约 6-8 小时才算“可信”。

**B. 最容易拖死的步骤**：问题 4 的收缩移动边界，以及为前三问选错几何简化或边界条件后被迫整体重写。

**C. 模型效果一般时能否写完整论文**：可以，因为问题链完整、图表强；但必须把数值收敛和物理一致性当作主要证据，不能把无真值的计算曲线当作实证。

**最大优势**：数学深度、四问连贯性和图表表现力都很高。

**最大风险**：缺乏内部真值，PDE 错误可能以“看起来很平滑”的方式隐蔽到最后。

**1.5 天可行性**：中等。队内有扎实 PDE/数值分析经验时可选；否则返工风险太高。

## B 题：无线电干扰源的快速自动定位与清除

**本质上要解决什么**

先解决带角度误差的几何交会定位和测点设计，再在频道未知占用、距离截断、角度误差与定向覆盖下做主动感知、路径规划和在线决策，本质接近部分可观测的多目标搜索问题。

**推荐的初步模型路线**

问题 1 用半平面/角域交集构造定位多边形，用凸包旋转卡壳求直径并用最小包围圆反例分析覆盖；问题 2 以交会角接近 90°、预期定位区面积/直径最小为准则选候选区；问题 3-4 用“网格扫频发现 + 多点角域融合 + 置信区主动缩小 + 频道级路径重排”的分层策略。

**核心判断**

- 题意和接口规则都很长，定向源的 `no_signal` 同时混合“无源、距离远、方向外”三种原因，理解成本高。
- 没有静态数据集；数据只能通过本地模拟器和在线服务运行中生成，外部依赖是五题中最强的。
- 子问题有自然链条：定位几何、测点选择、全向搜索、定向搜索；但前两问的局部结论不足以自动保证后两问的系统策略。
- 几何 baseline 很快，可用的端到端 baseline 必须等模拟器与账号流程打通。
- 验证有完整的演练模式，理论上很强；但黑箱随机案例、正式测试只有三次、现实运行限时和日志上传使结果可复现性受限。
- 模型空间最大：几何优化、贝叶斯更新、主动感知、多臂 bandit、POMDP、路径规划都能用；但这也是搜索空间失控的来源。
- 编程成本高：除策略本身，还需要 HTTP 幂等、超时恢复、日志、状态机、模拟器操作和正式测试防误触。
- 参数调试成本极高：搜索网格、频道扫描顺序、定位阈值、候选点、退出条件都与隐藏案例分布耦合。
- 无传统监督学习泄漏，但很容易过拟合少量演练案例，并将三次正式测试的随机性误当成策略优劣。
- 可做噪声、接收半径、源数、全向/定向比例、网格密度、退出阈值的稳健性分析，图表也很强；前提是可获得足够演练样本。
- Agent 可并行做定位几何、搜索策略、API 客户端和压力测试；但模拟器登录与正式测试不能真正并行，且同账号不能同时在两台设备使用。
- 两人可分为“几何/策略”和“接口/实验/日志”，但后者会成为串行瓶颈。

**A. 最快可信 baseline**：问题 1 几何 baseline 约 1 小时；如模拟器、登录和接口一次打通，全向源的端到端策略约 4-8 小时。如外部链路受阻，该时间无法保证。

**B. 最容易拖死的步骤**：问题 4 中定向源的无信号歧义，以及模拟器/账号/网络/测试机会的运行风险。

**C. 模型效果一般时能否写完整论文**：可以写出结构完整的策略论文，但如清除率低或正式测试日志不完整，证据空洞会直接暴露。

**最大优势**：创新空间和成果上限是五题中最高之一，且模拟器能给真正的策略反馈。

**最大风险**：成败依赖尚未本地验证的外部模拟器与有限次正式测试，技术与操作风险同时存在。

**1.5 天可行性**：偏低。只有在模拟器立即可用、团队熟悉在线搜索/机器人策略，且能在数小时内达到高清除率时才值得选。

## C 题：微网与外部电网电力调控策略

**本质上要解决什么**

在负荷平衡、储能容量、充放电功率、效率和期末 SOC 约束下，做从确定性日前优化、到光伏预报误差下的年度滚动调度、再到日内重预测调整和波动电价的多阶段能量管理。

**推荐的初步模型路线**

问题 1 建立 144 个 10 分钟时段的线性规划；问题 2 采用日前负荷/光伏预测 + 紧急购电惩罚的滚动回测；问题 3 用 0/6/12/18 时信息集做模型预测控制或两阶段随机规划；问题 4 在相同框架下换入波动电价。创新应放在信息集、约束和风险校准，而不是堆复杂预测器。

**核心判断**

- 题意理解成本中等偏高，难点主要在“每个时点已知什么”和购电费用结算规则，不是电力物理。
- 数据是五题中最完整之一：分钟级负荷/光伏/电价和小时级多时点光伏预报均可用，表格规则也明确。
- 子问题逻辑链很强：确定性调度、误差惩罚、日内调整、价格波动，一套核心约束可重用。
- baseline 很快：线性规划可直接给出功率平衡和 SOC 轨迹，SciPy `linprog/milp` 和 Matlab 均已可用。
- 结果易量化：总成本、紧急购电量、违约/超购费、峰谷套利、SOC 越界率和相对基准改善都能复算。
- 建模空间丰富且可竞争：确定性 LP、分位数预测 + LP、场景随机规划、鲁棒优化、MPC；容易做简单到复杂的递进对比。
- 编程成本中高，主要是日期/时段对齐、小时预报到 10 分钟决策的映射、334 天滚动运行、多类费用复算和大型结果表填写。
- 参数调试成本可控，但如同时尝试太多预测模型和场景生成方法，很容易浪费半天。
- 领域依赖中等：需理解储能 SOC、充放电效率和日前/日内结算，但不需潮流、网架等深度电力专业知识。
- 数据泄漏风险高于表面所见：在每天 0:00 的决策中如直接使用当天实际负荷或光伏，回测会严重高估。题面没有提供负荷预报，需明确建模信息集。
- 非常适合灵敏度、消融和稳健性分析：效率、容量、功率上限、预报误差、惩罚倍数、调整频率和场景数均有明确意义。
- 图表和论文叙事很友好：负荷-光伏-电池-电网堆叠图、SOC 曲线、成本分解、预报误差校准和月度热力图可直接支撑结论。
- Agent 可并行做数据对齐/泄漏审查、预测、优化、费用复算和图表；模块边界清晰。
- 两人宜一人负责数据/预测/回测信息集，一人负责优化/成本复算/结果输出，再交叉审查。

**A. 最快可信 baseline**：问题 1 单日 LP 约 45-90 分钟；完成一个不泄漏的小样本滚动回测与成本复算，约 3-5 小时。

**B. 最容易拖死的步骤**：没有明确每个决策时点的信息集，导致日前策略暗中使用未来真值；或对计划、调整、违约和紧急购电重复计费。

**C. 模型效果一般时能否写完整论文**：可以。即使复杂随机模型改善不大，只要有无泄漏滚动回测、可复算费用、约束可行性和误差/灵敏度分析，论文仍然证据充分。

**最大优势**：数据完整、基准快、结果可量化复算，且四问可复用同一优化核心。

**最大风险**：时序信息集和结算语义处理不严谨时，数值很好看但评价失真。

**1.5 天可行性**：高。前提是锁定一个简单可审计的预测方法，把时间留给滚动验证和论文证据。

## D 题：时频冲突检测与消解

**本质上要解决什么**

将重复使用的时间-频率矩形转化为冲突图，先精确枚举冲突，再在“每计划只调一个参数”、优先级、平移上限和少撤销的约束下做组合优化；再研究剩余资源容量和放宽间隔参数后的改善。

**推荐的初步模型路线**

先用半开区间枚举 + 占用栅格两个独立检测器交叉验证问题 1；为每个计划生成“保留、频段平移、时间平移、撤销”候选状态，用词典序多目标 MILP/CP-SAT 或先可行后改善的局部搜索求问题 2；问题 3 做同型 C 类周期矩形的最大装填；问题 4 将 C 类间隔候选纳入状态集。

**核心判断**

- 题意理解成本低到中等，时频冲突判定明确，数据字段只有 5 个。
- 数据风险最低：150 行无缺失，A/B/C 三类的频宽、时长、间隔和次数在类内统一，容易做规则检查。
- 子问题逻辑链很自然：冲突检测、冲突修复、剩余容量、额外自由度。
- baseline 是五题中最快的：问题 1 是确定性枚举，冲突对可以通过另一种占用栅格实现交叉核对。
- 验证能力最强：任一候选方案都可机械检查无冲突、一参数调整、平移上限、类别优先级和撤销数。
- 数学深度足够：区间图、冲突图、集合包装、图着色/独立集、组合优化和词典序多目标都能自然出现，不需要为深度而堆模型。
- 可竞争路线清晰：贪心/大邻域搜索、MILP、CP-SAT、模拟退火，可用同一可行性检查器公平比较。
- 编程成本中等：难点在候选动作间的冲突约束和多目标权重/词典序，而不在数据工程。现有 SciPy `milp` 和 Matlab 可用，不必先安装重型依赖。
- 参数调试成本中等：启发式需调邻域和权重；若采用分阶段词典序求解，可大幅减少“权重凭感觉”。
- 领域依赖低，半开区间和周期展开规则比无线电专业知识更重要。
- 几乎无数据泄漏风险，但有评价失真风险：“尽可能”形成多个优先目标，如不声明优先序或权重依据，只给一个方案不等于证明方案好。
- 非常易做消融、敏感性和稳健性：去掉某类动作、改变平移上限、改变优先级惩罚、比较贪心与精确求解、统计冲突密度都能生成直接证据。
- 图表友好：时频占用热力图、冲突网络、消解前后对比、各类保留/调整/撤销柱状图和 Pareto 曲线都有明确含义。
- 论文叙事很稳：检测器保证正确性，优化器改善资源配置，再用问题 3-4 说明容量与额外自由度的价值。
- Agent 并行适配极高：一路做独立冲突检测/验证，一路做 MILP，一路做启发式，一路做 Q3 容量和审查。
- 两人可清晰分为“规则解析/检测/交叉验证”与“优化/试验/图表”，然后交叉审查约束。

**A. 最快可信 baseline**：问题 1 约 20-40 分钟；包含交叉检测器的可信冲突列表约 1 小时；第一个完全无冲突的启发式消解方案约 2-4 小时。

**B. 最容易拖死的步骤**：问题 3 的时域资源上界和新增 C 类计划的默认参数若无法得到人类一致解释，“最多”就无法严格定义；其次是追求全局最优而让大型 MILP 耗尽时间。

**C. 模型效果一般时能否写完整论文**：能。只要方案完全可行、冲突检测可交叉复现、相对 baseline 有明确改善，即使不声称全局最优，也能写出证据充分的完整论文。

**最大优势**：数据小而干净、baseline 极快、所有约束和结果都可程序化验证，非常符合 1.5 天的风险偏好。

**最大风险**：问题 3 的有限时域和“新增 C 类”规格没有在题面中完整显式写出，需要先做解释性探针。

**1.5 天可行性**：高。前提是不在全局最优证明上过度投入，并在开工前固定 Q3 的时域解释。

## E 题：SEM 广告投放策略

**本质上要解决什么**

先评估日级方案/单元投放与注册效益，再按成本-效益将年度关键词分类，随后在单元预算下做关键词选择和日期安排，最后外推到 2026 年未来一周的不确定投放。

**推荐的初步模型路线**

先建立可审计的指标体系：CTR、CPC、浏览/点击、高质量浏览代理、注册的日级增量关联；分类使用分位数或单元内稳健标准化，避免任意阈值；问题 3 使用预算约束的多目标背包/组合优化；问题 4 用分层或 bootstrap 不确定区间 + 稳健预算分配。

**核心判断**

- 题意表面熟悉，但“综合效益”、“低成本/高效益”、“预期展位”和关键词关联都没有直接定义，隐性建模决策很多。
- 数据规模可管理，但粒度错位严重：日级数据到单元，关键词数据只有年度聚合，注册只有公司日总量，没有关键词-日-注册归因。
- 题面称 6000 多个关键词，附件只有 2227 条记录和 1884 个唯一关键词标识，必须解释数据口径，不能自行补全其余关键词。
- 子问题形式上连贯，但数据粒度使 Q2 的年度关键词分类难以直接支撑 Q3 的按日关键词投放，Q4 又要估计日级竞价和多项效果范围，跳跃较大。
- EDA 和四象限分类 baseline 很快，但“可信”的效益指标需要先解决归因和时间延迟。
- 结果可量化但真实验证有限：可以回测消费、点击和浏览，但无法直接验证“某个关键词在某日产生多少注册”。
- 建模空间很大，但许多路线受同一数据瓶颈限制：分类、因子分析、时序、因果推断、背包、鲁棒优化都可做，但复杂模型不会自动产生缺失的归因信息。
- 编程成本中高：需要处理多粒度表、特征工程、阈值稳定性、预算分配和不确定范围。
- 参数调试成本中高，且分类阈值、综合效益权重、注册滞后期和预算上限都容易成为主观参数。
- 领域知识依赖中高：需理解 SEM 指标、竞价机制、归因窗口和节假日行为，否则很容易把相关性当成效益。
- 数据泄漏/评价失真风险高：用全年统计分类关键词，再声称优化 2 月或 8 月的历史策略，就直接使用了未来信息；同时注册总数包含“SEM 等方式”，不是纯 SEM 转化。
- 可做阈值敏感性、指标消融、时间切分回测、不同归因滞后和预算摄动；这些分析对弥补数据局限非常重要。
- 图表容易且丰富：日历热力图、成本-效益散点、转化漏斗、关键词类别分布、预算效率曲线都很直观。
- Agent 可并行做 EDA、指标体系、时序验证、关键词优化和不确定性；但所有分支都依赖人类先确定“效益”的口径。
- 两人可分为“数据/归因/预测”和“分类/优化/图表”，但粒度错位无法靠并行本身解决。

**A. 最快可信 baseline**：EDA 和机械分位数分类约 1-2 小时；确定可辩护的效益指标、时间切分和简单预算分配后，约 4-6 小时。

**B. 最容易拖死的步骤**：为日级关键词投放伪造数据中不存在的转化率、关联或竞价时序，随后为了圆这个假设不断增加复杂模型。

**C. 模型效果一般时能否写完整论文**：可以，但必须诚实将目标收缩为可观测的代理指标，明确归因局限并用时间外验证。若直接声称优化注册或预测关键词日级表现，论文很容易证据过度。

**最大优势**：业务叙事和图表非常友好，指标、分类、优化、不确定性的章节结构容易组织。

**最大风险**：关键词、日期和注册之间没有同粒度链路，Q3-Q4 需要的若干重要量在数据中并不可观测。

**1.5 天可行性**：中等偏低。可以快速写出看似完整的分析，但要写出证据严密的论文并不快。

# 2. 统一评分表

## 关键分数解释

- **D 的 baseline 10、验证 10**：150 条数据可在几十分钟内完成冲突枚举，且每个结果都能用独立 checker 做硬约束校验。这是 1.5 天限制下最关键的优势。
- **D 的整体风险仍为 4 而不是 1**：Q3 时域上界与新 C 类默认规格有题意缺口，多目标“尽可能”也需要审慎形式化。
- **C 的验证 9**：365 天真值、多时点光伏预报和明确成本函数支持滚动回测。未给负荷预报且小时/十分钟粒度不同，所以不评 10。
- **C 的实现成本 7**：单日 LP 不难，但时序对齐、信息集、334 天滚动优化和五个大结果工作簿会占用显著时间。
- **A 的验证 3、上限 9**：PDE 和移动边界可以产生很强的数学论文，但附件无内部观测，主要只能验数值自洽而不能验真实准确性。
- **B 的创新/上限 10、整体风险 10**：主动感知与搜索策略的上限极高，但模拟器、账号、在线服务、黑箱案例和三次正式测试机会构成不可控的共同瓶颈。
- **E 的数据风险 8、验证 4**：表格本身不缺值，但关键词是年度聚合、注册是公司日总量，需要的日级关键词转化和竞价序列并不存在，且题面与附件的关键词数量不一致。

# 3. 排名

## 第一选择：D 题

D 题最符合“一天半内稳定完成高质量结果”的目标。它的数据小、规则明确、baseline 极快，且从冲突列表到最终方案都可机械验证。可在很早时得到一个“正确但不一定最优”的完整底座，后续时间全部用于改善多目标质量、容量上界和论文证据。

创新不需要靠复杂模型：词典序目标、候选动作压缩、冲突图分解、精确求解与大邻域搜索组合、可行性证书和资源容量界都是针对题目结构的改进。

## 第二选择：C 题

C 题数据完整、问题链清晰、验证丰富，是风险与上限最平衡的备选。它比 D 题有更强的统计回测和多阶段叙事，但数据对齐、预测信息集、结算语义和大量结果表带来更高的实现成本。

## 完整顺序

**D > C > A > E > B**。

- **A 题**作为条件备选：只有队内至少一人能熟练处理圆柱扩散 PDE、非线性系数和移动边界时，才可超过 E/B。
- **不建议 E 题**：不是因为它“不高级”，而是因为输出要求的日级关键词效果与输入的年度聚合关键词数据之间有实证断层。
- **最不建议 B 题**：它的上限最高，但在 1.5 天限制下，外部模拟器、黑箱搜索、定向无信号歧义和有限正式测试机会的联合风险过高。

# 4. 反向论证

## 假设选择 D 题是错的

1. **Q3 可能没有唯一可辩护的问题定义**。题面说不限制频段和时间平移幅度，又说不增加时频资源，但未显式给出总时域边界。如不先固定解释，时间可向后无限平移，“最多”就不成立。
2. **新增 C 类计划的规格可能被过度推断**。附件中现有 C 类均为频宽 3、持续 2、间隔 8、使用 12 次，但题面没有单独写明新增 C 类必须复制这一规格。
3. **多目标优先级可能被写成主观加权**。撤销、调整数、A/B/C 优先级、平移幅度之间没有数值权重。不同权重可能让“最优方案”完全变样。
4. **精确求解的候选冲突约束可能膨胀**。150 个计划每个都有多个平移状态，状态对之间的冲突禁配可能使 MILP 在时限内无法证明最优。
5. **简单数据可能造成论文同质化**。如果只有“枚举冲突 + 启发式平移”，数学叙事会显得单薄；必须补上可行性证书、下界/对照和灵敏度证据。

前三项中任一项在快速探针中无法得到人类认可的处理，都足以推翻 D 题首选。

## 什么情况下 C 题应超过 D 题

- D 题 Q3 的有限时域与新 C 类规格无法形成两名人类都认可的严谨解释。
- 30-45 分钟探针表明 D 题的候选状态求解无法快速产生完全可行解，或只能通过大量撤销得到劣质解。
- C 题的探针能明确“0:00 已知信息”、小时预报到 10 分钟决策的映射和费用结算，并在一个历史窗口上得到无泄漏的可行结果。
- 队内对时序回测、线性规划和能量管理的熟练度显著高于组合优化，并且能自动化生成五个结果工作簿。

# 5. 快速探针建议

## D 题可行性探针（30-45 分钟）

**输入**

- `D题/附件/附件1.xlsx`
- 人类暂定的 Q3 时域边界和新 C 类默认规格，明确标为待确认假设。

**操作**

1. 分别用区间对枚举和时频占用栅格构造两个冲突检测器，比较冲突对是否完全一致。
2. 为每个计划生成合法频段平移、时间平移和撤销候选，用一个贪心/局部搜索或小规模 MILP 生成首个消解方案。
3. 用独立 checker 重新展开全部周期区间，检查冲突数、每计划只调一个参数、平移上限和 A/B/C 保留/调整/撤销数。

**成功标准**

- 两个冲突检测器输出完全一致，并能解释一个边界接触不算冲突的样例。
- 在 5 分钟内求得至少一个经 checker 确认的完全无冲突方案，输出各类保留/调整/撤销数。
- 两名人类能就 Q3 时域和新 C 类规格形成可在论文中明示的解释。

**失败标准**

- 两个检测器在半开区间、周期展开或间隔定义上持续不一致。
- 候选动作模型无法在数分钟内得到任何完全可行解，或可行性必须依赖违反优先级的大量撤销。
- Q3 的有限时域与新 C 类参数无法合理定义。

## C 题可行性探针（30-45 分钟）

**输入**

- `C题/附件/附件1.xlsx`
- `C题/附件/附件2.xlsx`
- `C题/附件/附件3.xlsx`
- 储能容量、SOC、功率和 90% 效率参数。

**操作**

1. 对齐一个完整日的 144 个负荷/光伏/电价时段，并明确列出 0:00 时可用与不可用的字段。
2. 用线性规划求问题 1 的单日调度，然后将同一代码核心应用到一个历史日的“计划 + 真值结算”小样本。
3. 独立复算每个时段的供需平衡、SOC、充放电限制和总费用，标出小时光伏预报映射到 10 分钟的规则。

**成功标准**

- LP 在 1 分钟内稳定求解，144 个供需平衡和 SOC 约束全部通过，0:00 与 24:00 SOC 满足题意。
- 独立成本复算与优化器目标一致，对充放电效率的方向没有歧义。
- 能形成一个不使用未来真值的日前信息集，预报粒度映射也可复现。

**失败标准**

- 必须使用当日未来实际负荷/光伏才能形成计划，且无法对这一假设做出明确限定。
- 计划、调整、紧急购电和违约费用的复算无法一致，或 SOC/能量单位在 10 分钟换算中对不上。
- 数据日期与预报时点对齐不能在探针时限内达到零重复、零空缺、零跨日错位。

# 6. 最终建议

- **首选**：D 题。
- **次选**：C 题。
- **最大不确定性**：D 题 Q3 的有限时域和新增 C 类计划规格没有完整显式定义。
- **最终拍板前还需验证**：先执行 D 题 30-45 分钟探针，同时确认 Q3 解释；如解释不能被两名人类接受，或无法快速得到完全可行消解方案，立即改做 C 题探针后拍板。
