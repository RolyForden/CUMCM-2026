## 1. 总体问题结构

### 1.1 题目本质

微网（小区负载 + 光伏 + 储能 + 外网购电）的电力调控问题。决策粒度 10 分钟（每日 144 时段），储能容量 12000 kWh（允许区间 1200–10800 kWh），最大充放电功率 5000 kW，充放电效率 90%。目标：满足负载的前提下最小化购电费用，费用由正常计划购电、紧急购电（5 倍）、Q3 起新增的上下调结算构成。

计算内核不复杂：十分钟离散尺度下储能调度基本是线性规划（LP），Q3 是同一 LP 上的滚动重优化（MPC）。决定论文质量的是三件事：**决策时可获得的信息、预测误差的经济代价、跨日储能状态与调整结算**。

### 1.2 四问递进关系与统一变量

| 问题 | 决策时点 | 可用信息 | 核心新增困难 |
|---|---|---|---|
| Q1 | 单个典型日 0:00 | 当日价格、负荷、光伏预测均已知 | 确定性储能套利与终端 SOC（0:00 与 24:00 储电量相同） |
| Q2 | 每天 0:00（2025.2.1–12.31 输出） | 历史实测；当天真实负荷/光伏尚未发生 | 日前预测误差、5 倍紧急购电、跨日 SOC |
| Q3 | 0/6/12/18 时 | 新发布的未来 24h 整点光伏预测；过去已执行 | 多阶段调整、计划版本、非对称违约结算（下调 0.5 倍、上调 1.5 倍） |
| Q4 | 同 Q2/Q3 | 波动电价（附件 4）的可知性题面含糊 | 同时处理数量与价格两类预测误差、尖峰风险 |

**最重要的独立判断（两份文档一致）**：附件给出全年真实数据不代表每天 0:00 已知未来。使用未来实测值只能计算"完美信息最优下界（oracle）"，不可作为唯一正式策略；否则 Q2 紧急购电被人为压成零，Q3 预测更新失去意义。

统一物理模型（统一变量符号，四问共用，避免口径漂移）：

- 时段长 Δt = 1/6 h；负荷/光伏是功率（kW），进能量平衡前乘 Δt 转 kWh。
- 主模型拟采用交流母线侧充/放电量 c_t, d_t，储电量 E_t：
  g_t + g_t^emg + v_t − w_t + d_t = l_t + c_t，E_{t+1} = E_t + η_c·c_t − d_t/η_d。
- 边界：1200 ≤ E_t ≤ 10800，0 ≤ c_t, d_t ≤ 5000·Δt = 833.33；v_t ≥ 0 光伏，w_t ≥ 0 弃光（避免光伏富余且电池已满时模型无解）。
- 外网购电 g_t ≥ 0（题面不允许售电，反送规则见 P0 清单）。
- 目标：min 费用；LP 主目标 + 字典序吞吐量最小化（先最小化费用，再在费用不劣于数值容差的解中最小化 Σ(c_t+d_t)），避免任意 ε 惩罚改变主目标。

### 1.3 统一的模块接口（执行/核算与优化分离）

两份文档的独立结论：**优化器目标值仅供对照，论文数字以核算器对执行结果的复算为准**。固定五模块流水线：

| 模块 | 输入 | 输出 | 必须检查 |
|---|---|---|---|
| 预测器 | 截至决策时刻已发布的历史数据 | 带 issue_time/valid_time 的负荷、PV、必要时电价预测序列 | 无未来时间戳、长度与槽位正确 |
| 优化器 | 预测序列、当前 SOC、电价、冻结后的储能参数 | 购电/充放电计划及计划版本 | 求解状态、目标值、计划约束 |
| 执行器 | 计划、实际负荷/PV、冻结后的重调规则 | 实际 SOC、缺口、紧急购电、调整量、弃光 | 能量平衡、SOC/功率边界、跨日连续 |
| 核算器 | 实际执行记录、电价、冻结后的违约/溢价规则 | 总费用及正常、紧急、上调、下调分项 | 分项之和等于总费用、不重复计费 |
| 评价器 | 预测、计划、执行与费用结果 | 预测误差、约束违反与审计报告 | Oracle 与 causal 结果分离 |

Q1–Q4 共用一个核算器；统一账本为"正常购电 + 紧急购电 + 上调 + 下调违约 + 题面明确的其他费用"，不适用分项记零，不另写公式。

**P1（建模过程中必须冻结）：**

- **P1-1 "每天电价相同"的声明口径**：更像附件 1 的 144 点日内电价曲线每天重复，而非一天内恒价；论文必须显式声明所采用的解释。
- **P1-2 预报映射与视野**：`预报1小时`对应的有效时刻、小时值到 10 分钟的插值方案、跨日 24 小时视野如何进入只输出当天的策略，必须统一。
- **P1-3 "是否需要引入其他时刻预报"的判据**：以扣除调整成本后的总费用、紧急购电和稳定性共同判断，不能只比较 PV 预测误差。

**P2（输出阶段确认）：**

- **P2-1 结果模板完整性**：模板部分工作表只列首尾日期与省略号行；最终必须展开 2025.2.1–12.31 全部日期，同时保持原工作表与列结构（紧急购电表同样处理）。

**配置项（非题意口径，不入冻结清单）：**

- **求解器**：HiGHS（dual simplex 主引擎 + IPM 交叉验证）为默认配置；换求解器仅作对拍手段。

> 冲突说明：P0-2、P0-3、P0-4、P0-8 在两份文档间无结论冲突，但旧方法地图将效率、结算、弃光列为"必须先澄清的题意"（即已知不确定项）；调研报告进一步将其制度化为一票 P0 冻结清单。融合版采用后者——**不确定 ≠ 无法开工，条件性默认 + 敏感性 + 人类冻结**。

### 1.6 推荐总体建模流程

1. 冻结 P0/P1/P2 清单（0-3 小时，见 §15 时间预算）；建立 144 槽位适配器与统一长表：`decision_time, valid_time, date, slot, price, load_actual, pv_actual, pv_forecast, forecast_issue, lead_hour`。
2. Q1 条件性回归测试（LP，HiGHS 双引擎对拍）→ 锁定单位、时间映射、效率口径、能量平衡残差。
3. Oracle 下界（完美信息全年 LP）→ 保证紧急购电在可行条件下降至零，作为校验与下界。
4. Q2 因果 walk-forward：1 月 warm-up，2–12 月逐日回测，点预测与候选分位比较，SOC 跨日传递。
5. Q3 四时点确定性 MPC：锁定已执行区间与真实 SOC，只重算未来；更新时点逐级消融（0:00 only → +6 → +12 → +18）。
6. Q4：Q4-2 复用 Q2、Q4-3 复用 Q3，接入冻结后的电价口径；完美电价 oracle 并列展示。
7. 独立执行器 + 统一核算器复算全部数字 → 填官方模板 → 无泄漏审计 → 敏感性/消融 → 论文。
8. 增强项（场景/CVaR/终端价值等）仅在主线全部闭环后最多选一项。

## 2. 第 1 问

目标：已知单日负荷、光伏预测和分时电价，在"供电不低于负载、0:00 与 24:00 储电量相同"下，制定 0:00 当天的计划购电策略（144 时段，输出表 1/表 2 与 result1.xlsx）。

### 2.1 候选方案 A：确定性 LP

- **核心思想**：线性状态转移连接相邻 SOC；购电、充/放电、弃光为非负变量；目标 min Σ p_t g_t，终端约束 E_144 = E_0。
- **数学模型**：见 §1.2 统一模型；Q1 额外强制 E_144 = E_0。
- **核心假设**：全部输入（负荷、光伏预测、电价）在 0:00 已知；电池效率与功率边界线性；正电价。
- **数据处理**：附件 1 四列功率/电价 → 乘 Δt 转 kWh；时间标签按 P0-1 冻结的槽位映射；检查每天恰 144 点、跨日标签不丢失。
- **求解算法**：LP 直接求解（HiGHS dual simplex 主引擎 + IPM 交叉验证）；事后检查同时充放电，若有经济意义的同步充放电再升级 MILP（见方案 B）。
- **评价指标**：目标值（条件性回归值见下）、最大能量平衡残差、SOC 越界次数、同时充放电次数、与规则法（§2.3）成本差。
- **优点**：全局最优、可解释、秒级、稳定；四问共用内核与核算器。
- **缺点**：单路径模型不表示预测误差；无显式充放电互斥（通常不经济，见 §2.2）。
- **实现难度**：低（LP 约半天～1 天，含核算器复算）。
- **风险**：P0-1 时间映射若错，全部四问继承同一错位；E_0/效率口径未冻结时只能出条件性数字。
- **数值锚点（条件性回归测试值）**：仅在 E_0 = 6000、η_c = η_d = 0.9、允许弃光禁止反送等候选假设下，用 SciPy HiGHS 复算得 **35,126.948589 元**，最大能量平衡残差约 1.14×10⁻¹³（dual simplex 与 IPM 一致）。该值用于锁定单位与约束的回归测试，**不是口径冻结前的标准答案**；本地各资料包中的近似结果（含"约 35,126.95 元"）尚未按原代码复现。

### 2.2 候选方案 B：MILP 互斥调度

- **核心思想**：加二进制 z_t，0 ≤ c_t ≤ C_max·z_t，0 ≤ d_t ≤ D_max·(1−z_t)，保证充放电绝对互斥。
- **数学模型**：方案 A + 144 个二进制互斥约束。
- **核心假设**：需要严格互斥（存在负电价、补贴、启停费或退化成本时）。
- **数据处理**：同方案 A。
- **求解算法**：MILP（HiGHS 内置）。
- **评价指标**：与 LP 目标值差异、同时充放电次数（应为 0）。
- **优点**：物理约束最严；负电价等扩展下依然正确。
- **缺点**：本题电价非负、往返效率 < 1，LP 通常自然互斥；144 个二进制在 Q1 无妨，但全年约 4.8 万个会显著增加计算与排错负担。
- **实现难度**：低—中。
- **风险**：把"约束实现变体"误当独立建模路线。

### 2.3 候选方案 C：规则型净负荷优先/价序充放电

- **核心思想**：光伏先覆盖负荷；富余光伏在容量允许时充电；缺口优先在低价购电/高价放电；按电价分位数设充放电阈值。
- **数学模型**：无优化器，阈值规则。
- **核心假设**：阈值与优先级固定；忽略未来机会成本。
- **数据处理**：同方案 A。
- **求解算法**：顺序扫描。
- **评价指标**：可行率、总成本、与 LP 成本差、SOC 越界数。
- **优点**：实现快（约半天）、可解释；暴露单位/效率/SOC/索引错误的最佳 baseline。
- **缺点**：通常非最优；对终端状态与未来价格处理粗糙。
- **实现难度**：低。
- **风险**：只作回归测试与保底策略，不作主结果。

### 2.4 方案比较与推荐

- **主方案：A（确定性 LP）+ 字典序吞吐量最小化**，HiGHS 双引擎对拍，核算器独立复算。
- **备选方案：B（MILP）**——仅在 LP 解中出现有经济意义的同时充放电时启用；C（规则法）作为回归测试与单位检查。
- **不推荐方案**：Q1 直接上全年联立 LP（信息范围错误）；元启发式（LP 已给全局最优）；AC-OPF（题面未给网络拓扑与线路参数，详见 §11）。
- **推荐理由**：LP 与题面结构高度匹配、最优性可证、可审计，是 Q2–Q4 的共同内核；MILP 只是实现变体，不是新经济模型。

## 3. 第 2 问

目标：每天电价相同、负载与光伏随时间变化，供电不可低于负载（低于则 5 倍紧急购电）；除紧急购电外按计划购电量计费。每天 0:00 制定当天计划，输出 2025.2.1–12.31 的 result2.xlsx（含紧急购电量清单）。核心难点：当天真实负荷/光伏在 0:00 未知 → 预测误差直接触发 5 倍罚价；跨日 SOC 连续。

### 3.1 候选方案 A：完美信息全年/逐日 LP（oracle）

- **核心思想**：把当天真实负荷、光伏放入 LP 排计划，差额由 5 倍紧急购电变量补；可全年一次联立或逐日传递 SOC。
- **数学模型**：§1.2 统一 LP，负荷/光伏 = 实际值；g_t^emg 计 5p_t。
- **核心假设**：未来完全已知。
- **数据处理**：官方附件 2（负载 + 实测光伏两张表）；跨日 SOC 传递。
- **求解算法**：LP；全年联立约 24–29 万连续变量，秒至分钟级。
- **评价指标**：理论下界成本、紧急购电量（可行条件下应为 0——见探针 2）、与因果策略的 gap。
- **优点**：给出理论下界、便于验算、暴露单位/约束错误。
- **缺点**：不可执行、严重信息泄漏；全年一次性 LP 还会利用年底之前所有未来信息。
- **实现难度**：低。
- **风险**：把它当作正式答案（多套本地成品论文的通病）——Q2 零紧急购电或异常低成本通常来自泄漏。

### 3.2 候选方案 B：因果点预测 + 确定性 LP

- **核心思想**：每天 0:00 只用当时已发布数据预测当天净负荷 N_t = L_t − PV_t（或分别预测 L、PV），点预测轨迹送入 LP。
- **数学模型**：§1.2 统一 LP；预测器为外生输入。
- **核心假设**：历史规律（季节/星期/时刻）在未来保持稳定；点预测足以代表分布中心。
- **数据处理**：1 月 warm-up 建立预测器；2–12 月逐日 walk-forward，日末用当天实测更新模型；严格按决策时间过滤信息（禁止未来实测进特征，禁止全年预拟合）。
- **求解算法**：334 个小 LP（逐日 144 步），分钟级。
- **评价指标**：实际总费用（核算器复算）、紧急购电量、MAE/RMSE（分季节/时段/提前量）、与 oracle regret、与规则法改善率。
- **优点**：因果、可执行、代码增量小。
- **缺点**：对 5 倍缺口代价不敏感（均值预测对短缺侧无倾斜）；预测误差全部落到紧急购电。
- **实现难度**：中。
- **风险**：预测器实现中悄悄引入未来信息（最常见失败模式）。

### 3.3 候选方案 C：因果分位数（报童式）计划 + LP

- **核心思想**：用历史预测残差的条件分布，把计划量抬高到经济最优分位。单时段简化：多计划 1 kWh 边际成本 p，少计划 1 kWh 额外成本 5p，损失 ℓ(q,N) = pq + 5p(N−q)_+，一阶条件 P(N > q) = 1/5 → q* = F_N⁻¹(0.8)。以候选分位净负荷轨迹作为 LP 输入，储能统一调度。
- **数学模型**：报童临界分位（解析）+ §1.2 统一 LP（执行）。
- **核心假设**：残差分布可由历史估计（同星期/时段/相近日加权）；两侧边际成本比 = 1:5。**注意**：分位结论在单期、无跨期耦合时严格；电池跨时段耦合后各时段不能完全独立按 0.8 分位决策。
- **数据处理**：与 B 相同的历史残差集；候选分位 0.7/0.8/0.9 与点预测在同一 walk-forward 上比较。
- **求解算法**：分位数估计（经验/条件分位）+ LP，计算量与 B 近似相同。
- **评价指标**：实际总费用、紧急购电量、pinball loss 与 0.8 分位实际覆盖率、相对点预测的成本下降。
- **优点**：经济解释强（0.8 不是拍脑袋安全系数）、增量小、直接对应 5 倍罚价。
- **缺点**：逐时分位忽略残差的日内相关性（连续阴天/峰谷相关）与 SOC 尾部风险。
- **实现难度**：中。
- **风险与冲突标记**：资料调研记录称"许老师"资料显示 0.8 附近 walk-forward 总成本最好、负荷 D-7 + 光伏 D-1 是强基线——**该结论尚未复现，不得直接采信**。调研报告已把 0.8 从"推荐"降格为"候选"：主策略必须以实际总费用、紧急购电量和可行性共同选择，而不是按单步解析推导或未复现资料预先指定。

### 3.4 候选方案 D：场景两阶段随机规划（SAA）

- **核心思想**：决策时生成 K 条整日净负荷误差轨迹；日前变量 g,c,d 对所有场景共享，实际发生后的紧急购电、弃光、修正为场景相关变量；目标 min C^DA(x) + Σ_k π_k C^RT(x, y_k)。
- **数学模型**：两阶段随机 LP（场景共享日前计划 + 场景相关补救）。
- **核心假设**：历史残差块代表未来联合误差；非预见性约束正确。
- **数据处理**：按季节/星期类型抽取"整日残差块"，或对相似日残差做块 bootstrap；**禁止每时段独立加高斯噪声**（破坏阴晴与峰谷时间相关）。
- **求解算法**：LP，规模约为基础 LP 的 K 倍。
- **评价指标**：样本外平均成本、P90/P95/CVaR、应急量、相对 oracle regret、多随机种子稳定性。
- **优点**：真正优化期望总费用、表示误差轨迹相关性、可扩展价格场景。
- **缺点**：1 月样本少，场景概率与尾部估计不稳；非预见性约束容易写错；内存与调参膨胀。
- **实现难度**：中—高。
- **风险**：对 1.5 天队伍是最大陷阱之一（场景、非预见性、结算同时出错）。

### 3.5 候选方案 E：预算鲁棒优化（Bertsimas–Sim）

- **核心思想**：为各时段误差设上下界，用预算 Γ 限制"同时达最坏值"的时段数；扫描 Γ 得成本—安全折中。
- **数学模型**：budgeted uncertainty set 鲁棒对应式（保持线性可解）。
- **核心假设**：区间边界合理；最坏方向与预算结构覆盖主要风险。
- **数据处理**：分时距误差分位范围，或有限历史给出的保守上下界。
- **求解算法**：鲁棒线性规划（规模略增）。
- **评价指标**：样本外违约率、最坏成本、名义成本增加、应急量。
- **优点**：不要求完整概率分布、保守度可解释（Γ）、仍线性可解。
- **缺点**：区间与 Γ 主观；可能过度保守；对时间相关性表达有限。
- **实现难度**：中（1–2 天）。
- **风险**：需要按"预测时距 × 时段"重新标定区间，不能套统一百分比；超出 Q2 最小主线范围。

### 3.6 方案比较与推荐

- **主方案：B + C 的组合**——因果简单预测（D-1 / D-7 / 同星期日衰减三选一）作为必做基线；点预测与候选分位（0.7/0.8/0.9）在同一 walk-forward 上比较，**胜出者进入主结果**。
- **备选方案：A（oracle）**——必做，但只作下界与校验；D/E 为主线完成后的增强候选。
- **不推荐方案**：把 A 当正式答案；全年一次性联立 LP（信息范围错误）；场景随机规划作为首发主线（1.5 天时限）。
- **推荐理由**：B/C 因果、可执行、直接回应 5 倍罚价的经济结构；walk-forward 比较机制保证分位选择由数据决定而非拍脑袋。oracle 与 causal 并列展示"可执行性代价"。

## 4. 第 3 问

目标：每天 0:00 用 0:00 预报制定计划，6:00/12:00/18:00 可用新发布预报调整购电策略；计划高于调整的部分按 0.5 倍违约电价，调整高于计划的部分按 1.5 倍；总费用 = 计划 + 紧急 + 调整相关费用。输出 result3.xlsx（计划购电量、调整购电量、最终充放电量、最终紧急购电）。**必须分析是否需要引入其他时刻的预报**（题面明确要求）。

### 4.1 候选方案 A：确定性滚动 MPC（四时点重优化）

- **核心思想**：0:00 建原计划；6/12/18 时锁定已执行时段与真实当前 SOC，用新预测只重算剩余时段；只执行到下一次更新前的动作。计划版本（q⁽⁰⁾, q⁽⁶⁾, q⁽¹²⁾, q⁽¹⁸⁾）在内部审计表保留，正式结果只写题目要求字段。
- **数学模型**：§1.2 统一 LP 内核 + 滚动时域控制框架；结算式（候选，P0-8 冻结）：C_t = p_t·min(q^old, q^new) + 0.5p_t(q^old − q^new)_+ + 1.5p_t(q^new − q^old)_+（不重复计费的"替代价"解释；等价实现可单列已承诺成本与增减量，但必须避免既付旧计划又付重叠部分）。
- **核心假设**：当前 SOC 可准确观测；最新预测为最佳单轨迹；计划版本基准与结算语义已冻结（P0-8）。
- **数据处理**：附件 3 按 issue_time + valid_time 建 forecast vintage；未来 24h 跨日时保留跨日有效时间不截断；小时 → 十分钟用零阶保持/分段线性/PCHIP 比较，按因果验证中的预测误差与最终运行费用选择（**禁止用未来实际光伏作插值锚点、禁止跨发布批次拼接后发预测**）；6/12/18 时只能用对应时刻新发布的预测，不得提前使用。
- **求解算法**：逐日约 4 次小 LP（4 × 334 次/年），通常可接受。
- **评价指标**：实际总费用（核算器复算）、相对 0:00 固定计划的节省、调整次数/幅度、紧急购电量、更新时点逐级消融（0:00 only → +6 → +12 → +18）。
- **优点**：与题面信息发布机制直接一致；复用 LP 内核；严格防泄漏。
- **缺点**：点预测误差仍可能造成尾部高成本；短视终端会扭曲 SOC；结算口径易错。
- **实现难度**：中（1–2 天）。
- **风险与冲突标记**：资料调研记录中的"6:00/12:00 更新最有价值、18:00 收益接近零"与"不同实现 Q3 节省率约 0.13%–3.18%"均未复现。**0.13%–3.18% 的巨大差异被两份文档判定为费用口径不统一所致，不是算法优劣**——必须先冻结 P0-8，主结果只允许一个核算口径；另一种解释至多作敏感性。

### 4.2 候选方案 B：随机 MPC（场景 + 滚动）

- **核心思想**：每次更新用概率场景（整日残差块）重优化，风险控制更完整。
- **数学模型**：场景两阶段 LP × 更新次数；可选 + λ·CVaR_0.9 控制尾部。
- **核心假设**：场景代表联合误差；非预见性正确。
- **数据处理**：同 §3.4 场景构造。
- **求解算法**：场景数 × 更新次数个小 LP。
- **评价指标**：平均成本、尾部 CVaR、应急量、相对确定性 MPC 增益。
- **优点**：联合考虑误差轨迹与更新信息。
- **缺点**：模型与调参明显膨胀；1.5 天队伍不现实。
- **实现难度**：高。
- **风险**：最容易在场景、非预见性、结算三处同时出错。

### 4.3 候选方案 C：CVaR / DRO / SDDP 扩展

- **CVaR 附加项**：在期望成本外惩罚最坏 α 尾部（min E[C] + λ·CVaR_α(C)），适合极端缺口；是"最现实的附加项"（两文档一致）。
- **Wasserstein DRO**：以经验分布为中心建 Wasserstein 球优化最坏分布；有限样本保证好，但半径标定难、重构复杂（3–5 天）。
- **SDDP/ADP**：把 SOC 当状态、未来成本函数切平面近似，直接回答"今天应为明天保留多少电"；但 144 段/日的多阶段结构容易膨胀（4–7 天）。
- **实现难度**：中—很高；**全部为主线完成后的增强项**，不进入 Q3 主路线。

### 4.4 方案比较与推荐

- **主方案：A（四时点确定性 MPC）**，字面结算式 + 冻结口径；更新时点逐级消融回答"是否需要引入其他时刻预报"（题面明确要求，也是论文的定量亮点）。
- **备选方案：B/C** 为主线闭环后的可选增强（最多一项）。
- **不推荐方案**：随机 MPC 首发（复杂度 + 结算双重风险）；修改已执行时段的任何"重优化"（违反非预见性，直接判错）。
- **推荐理由**：MPC 不是新求解器，而是"获得新信息—更新状态—重算未来—只执行近期动作"的控制框架，与题面发布机制一一对应；结算口径冻结后风险可控。

## 5. 第 4 问

目标：外网电价实时波动（附件 4，10 分钟级），重新计算问题 2（result4-2）与问题 3（result4-3）。新增难点：电价在决策时是否可知题面含糊（Q4 的 0:00 计划能否用当天未来电价？Q3 各更新时点能否用之后时段的电价？），且电价与净负荷误差相关（高负荷与高价共现）。

### 5.1 候选方案 A：完美电价 LP/MPC（oracle）

- **核心思想**：直接使用附件 4 未来全天真实电价排计划/调整。
- **数学模型**：§1.2 统一 LP/MPC，价格 = 实际值。
- **核心假设**：未来全天电价在决策时已知。
- **数据处理**：同 Q2/Q3，价格换附件 4。
- **求解算法**：同 Q2/Q3 内核。
- **评价指标**：价格完美信息下界、与因果价格策略的 gap。
- **优点**：下界、易复用、与数量 oracle 并列。
- **缺点**：题意未保证可知性；若直接当正式答案 = 信息泄漏。
- **实现难度**：低。
- **风险**：与正式结果混写（两文档共同的失败模式）。

### 5.2 候选方案 B：价格预测 + LP/MPC（因果）

- **核心思想**：电价不可知口径下，用 D-7 或同星期日历史价格作基线预测，实际结算仍按附件 4 真实价格；只有简单基线明显不足时再试滚动中位数、SARIMA 或 LightGBM（不引入深度模型）。
- **数学模型**：§1.2 统一内核 + 价格预测器；电价与净负荷联合误差在增强项中处理（联合场景，保留高负荷与高价共现）。
- **核心假设**：电价历史规律稳定；只知历史/当前价格。
- **数据处理**：价格预测按决策时间切片；结算用真实价。
- **求解算法**：同 Q2/Q3，小幅增加。
- **评价指标**：实际总费用、价格预测 MAE/RMSE（skill score 相对 persistence）、相对完美电价 oracle 的 regret。
- **优点**：可执行、论证更强（多一类预测误差的代价可量化）。
- **缺点**：多一类预测误差；价格尖峰可能造成尾部成本。
- **实现难度**：中。
- **风险**：价格预测基线比想象中强/弱都会改变结论——必须先跑基线再决定是否升级模型。

### 5.3 方案比较与推荐

- **主方案：先由人类冻结电价可知性，再选一个主口径**（若提前可知 → A 为正式；若不可知 → B 为正式）；另一口径 + 完美价格 oracle 作对照。**结果模板只提交一个冻结后的主口径，不双口径混写。**
- **推荐理由**：题面含糊必须显式处理；双口径（oracle 下界 + 因果主结果）并列展示"可执行性代价"是论文叙事核心。Q4-2 复用 Q2 预测器、Q4-3 复用 Q3 MPC，不另起炉灶。

## 6. 各问之间的模型衔接

- **可复用变量/结果**：统一物理模型（c,d,E,g,v,w 定义）四问共用；统一时间槽位映射与长表一次建立；Q1 的 LP 内核是 Q2–Q4 的唯一优化器；Q2 的负荷预测器被 Q3 的 0:00 计划直接沿用；Q2 的 walk-forward 框架被 Q4-2 复用，Q3 的 MPC 框架被 Q4-3 复用。
- **可共用模型**：核算器全题唯一（分项记账，不适用分项记零）；执行器规则一次冻结后四问通用；评价器与无泄漏审计脚本四问通用。
- **必须独立完成的步骤**：Q1 的终端约束 E_144 = E_0 只属于 Q1；Q3 的计划版本与调整结算只属于 Q3/Q4-3；Q4 的价格口径决策只属于 Q4；各问的结果模板字段不同（result1–result4 系列）。
- **防止论文割裂**：全文只讲一个优化内核 + 两个信息基准（oracle/causal）+ 逐问递进的信息集扩展；费用账本统一；各问结论都用"相对 oracle 的可执行性代价"与"相对上一问的增量价值"串起来；Q3 的消融（0:00 only → +6 → +12 → +18）本身就是"信息增量价值"的主线叙事。
- **衔接陷阱**：Q1 若用逐日独立优化（终端 SOC 自由）会透支最后时段储能；Q2–Q4 每天重置 SOC 6000 会虚构能量——跨日传递是硬要求（P0-6）。

## 8. 当前推荐的整体技术路线（1.5 天主线）

**数据处理 → 建模 → 求解 → 验证 → 敏感性分析 → 可视化 → 论文呈现**

- **数据处理（0-3 h）**：官网原包取数（不完整副本不得使用）→ 144 槽位适配器（P0-1）→ 统一长表（decision_time / valid_time / issue_time / slot / 价格 / 负荷 / 光伏 / lead_hour）→ 数据审计（重复、缺失、负值、每天 144 点、跨日标签、SOC 连续）。
2. **建模（3-12 h）**：冻结 P0/P1/P2 并写入 DECISIONS.md → 统一 LP 内核 + 字典序吞吐最小化 → 独立执行器 + 统一核算器 → Q1 条件性回归（35,126.948589 锚点）→ Q2 因果点预测（D-1/D-7/同星期日三选一）+ 候选分位（0.7/0.8/0.9）→ Q3 四时点 MPC + 计划版本账本 → Q4 一个冻结电价口径。
3. **求解（12-22 h）**：HiGHS dual simplex 主引擎 + IPM 交叉验证；Q2/Q3 先抽样日验证再跑全年；Q4-2/Q4-3 复用 Q2/Q3 管道。
4. **验证（22-28 h）**：核算器复算全部费用分项（不信任优化器目标值）→ 官方模板填写 → 约束残差/费用/时间戳三重审计 → 无泄漏审计（证明每个 decision_time 只用到截止时刻的信息）。
5. **敏感性分析（随验证并行，按 §12.3 必做/余量两级执行）**：必做——效率两口径、E_0、紧急倍率 3/5/8、更新时点逐级消融、终端 SOC 规则、弃光开关；余量——容量/功率缩放、上下调倍率 ±20%、Morris/Sobol、压力情景。
6. **可视化**：典型日（Q1）SOC/充放电/购电曲线；四问费用分解堆叠图；oracle–causal gap 图；预测误差随提前量/季节的热图；MPC 更新时点消融柱状图；跨日 SOC 轨迹。
7. **论文呈现**：一个内核 + 两个信息基准（oracle/causal）+ 逐问递进；Q2 用 walk-forward 说明为何选某分位/点预测；Q3 用消融回答"是否需要其他时刻预报"；Q4 明确电价口径假设与可执行性代价；所有数字来自核算器复算。

**停止规则**：第 20 小时 Q1–Q3 未闭环 → 立即删除所有增强项、复杂预测器与非必要敏感性，只保留正确可验证的四问主线。

## 12. 评价指标与验证设计（统一清单）

### 12.1 优化结果主指标

1. 实际总购电成本：计划、上调、下调、紧急四部分分别报告（同一总成本会掩盖结算误读；核算器复算，不信任优化器目标值）。
2. 相对 oracle regret：(C_policy − C_oracle)/C_oracle；oracle 只作不可执行下界。
3. 相对 baseline 改善率：与"无储能"、规则法、0:00 固定计划比较。
4. 可靠性：紧急购电量、紧急时段数、供能缺口、SOC/功率越界次数、跨日 SOC 断点、同时充放电次数。
5. 运行性：单日/单次更新时间、求解间隙、求解失败次数、峰值内存。
6. 储能使用强度：能量吞吐量、等效满循环数、SOC 边界停留比例、充放电切换次数。
7. 调整稳定性：调整绝对量、调整次数、计划—最终执行偏差。

### 12.2 预测与情景指标

- 点预测：MAE、RMSE、MBE，按预测时距和白天时段分层；skill score 相对 persistence/0:00 forecast baseline（不许只报 RMSE）。
- 概率/分位预测：pinball loss 与对应覆盖率（成对报告）；完整分布用 CRPS。
- 业务价值：同一优化器下比较预测来源的真实结算成本，不以 RMSE 单独决定方法。
- 验证切分：按日期滚动起点回测，训练和标定只用当时已发布数据；普通随机 K 折泄漏未来，禁用。

### 12.3 统计比较与敏感性

**敏感性分两级排期（交叉验证修正项）：必做项随主线验证并行，余量项只在主线全部闭环后执行；两者不平级，防止挤占 22–28h 审计/模板窗口。**

必做（主线内，随验证并行）：

- 效率两口径（η_c=η_d=0.9 vs √0.9）与总效率 ±5%。
- 初始 SOC {1200, 6000, 10800}。
- 紧急倍率 3/5/8。
- MPC 更新时点逐级消融（0:00 only → +6 → +12 → +18）。
- 终端 SOC 规则（跨日传递 vs 逐日复位对照）、弃光开关。

余量才做（主线全部闭环后，按时间余量取舍）：

- 容量/功率 0.5/1/1.5 倍（辨认瓶颈是功率还是容量）。
- 上/下调倍率 ±20%。
- Morris 筛查 8–15 个参数 → 最重要的 3–5 个做 Sobol。
- 压力情景注入（缺测、重复时间戳、极端价格、连续低光伏、高负荷峰值）；整月/整季留出做分布漂移压力测试（不做随机行切分）。
- CVaR 的 α、λ 与鲁棒 Γ、DRO 半径画 Pareto 曲线。

通用做法：

- 每日成本差做配对比较：均值、中位数、P90/P95、bootstrap 置信区间；保留季节分层（春分/夏至/秋分/冬至附近），不只汇总全年均值。
- 随机方法用多个固定种子，报告成本与运行时间离散度。

## 13. 常见失败模式（融合清单，前 13 条为旧方法地图保留，14–20 为调研报告新增）

1. 把 kW 直接当 kWh，漏乘 1/6 小时。
2. 对效率重复计损或完全不计损；把"90%"口径默认为唯一解释。
3. 每天独立把 SOC 重置为 6000 kWh，破坏跨日物理连续性。
4. 逐日无终端价值地把电池在 24:00 前耗空，得到虚假低成本。
5. 把附件中的全年实测负荷、光伏或电价当成每日 0:00 已知信息。
6. Q3 更新计划时修改已经执行的时段，违反非预见性。
7. 把 50%/1.5 倍规则写成错误方向，或把"额外费用"和"最终结算价"混为一谈。
8. 未设置弃光/富余变量导致可避免的不可行；或用大松弛变量掩盖真实错误。
9. 未检查同时充放电，或一开始就加大量二进制变量导致不必要的求解负担。
10. 情景逐时独立抽样，破坏云团造成的连续误差和预测时距相关性。
11. 只报告 RMSE，不报告实际成本、尾部成本和可靠性。
12. 用同一年数据同时标定不确定集、调参和报告结果，产生选择偏差。
13. 以深度模型或元启发式的复杂度替代可解释、可审计的增益证据。
14. 直接按时间字符串连接源数据与结果模板（标签口径不统一，见 P0-1）。
15. 用未来实际光伏作插值锚点，或跨发布批次拼接后发预测。
16. 把后发预测用于更早的决策时间（forecast vintage 错乱）。
17. 先在全年数据上拟合预处理器再回测（时间泄漏的另一形式）。
18. 结算既支付整个旧计划又再次支付重叠部分（重复计费）。
19. 优化器目标值直接写入论文，绕过执行器/核算器复算。
20. 1 月只训练预测器却无说明地在 2 月 1 日重置电池（冷启动不连续）。

## 14. 探针与验收门槛

探针 = 快速锁定口径错误的实验。融合后按依赖顺序排列：

- **探针 1：单日 LP 与 MILP 互斥诊断**（数据：附件 1）。对比：无储能、规则法、LP、MILP；扫描两种效率口径、允许/不允许弃光、E_144 = E_0。通过标准：能量残差 < 数值容差，SOC 全程合法，LP 无同时充放电时与 MILP 目标一致，规则法成本不低于 LP；条件性锚点 35,126.948589。价值：最快锁定单位、索引、时间映射、互斥建模。
- **探针 2：Q2"应急量应为零"支配性测试**（前提：官方附件 2 完整数据——已满足）。普通确定性 LP vs 显式应急变量 LP。通过标准：普通购电无限且便宜时应急量为 0；否则逐项查购电上限、时序、单位、结算公式。价值：直接证伪大量表面可运行但逻辑错误的模型。
- **探针 3：0:00 固定计划 vs 6/12/18 滚动 MPC**（前提：完整实测光伏 + 严格按发布时间构造信息集）。对比：0:00 only、只 12:00 更新、6/12/18 全更新、oracle。通过标准：滚动策略不使用未来发布预测；增益在多数季节和代表日期存在，而非只在全年均值微弱改善。价值：直接回答"是否需要引入其他时刻预报"。
- **探针 4：MPC、SAA-CVaR 与预算鲁棒的小规模压力测试**（30–60 个滚动日期；按预测时距建立保持时间相关的误差情景）。**定位：主线闭环后的准入实验，不占主线排期**（见 §15）。对比：确定性 MPC、期望成本 SAA、SAA+CVaR、3 个 Γ 的预算鲁棒；压力：连续低光伏、高负荷、价格尖峰、误差分布漂移。通过标准：高阶方法必须在尾部损失或可靠性上给出可复现改善，否则保留简单 MPC。价值：用有限实验判定是否值得投入 DRO/SDDP，而不是先做复杂实现。

推荐实验顺序（两文档一致）：规则法/LP 共同内核 → 因果回放比较固定计划 vs 滚动 MPC → 预测误差确实造成明显尾部成本时才进入 SAA-CVaR 与预算鲁棒 → DRO/SDDP/安全 RL 由探针证据触发，不因"新"而成为默认路线。

## 15. 两人分工与时间预算（36 小时，已映射项目阶段机）

> 阶段映射依据 `docs/AGENT_OS_DESIGN.md` 第 26 节：BOOTSTRAP → TOPIC_SELECTION → SOLVING → MODEL_FREEZE → PAPER → FINAL_CHECK。当前处于 SOLVING（题意冻结阶段）。

| 人员 | 主责 | 交叉复核 |
|---|---|---|
| A | 数据时间索引、预测与 walk-forward、Q2/Q4-2 | 检查 Q3 forecast vintage 和无泄漏 |
| B | LP 内核、仿真结算、Q1/Q3/Q4-3 | 检查 Q2 SOC 连续和费用拆分 |

1. **SOLVING（0–3 h）**：共同冻结 P0/P1/P2；144 槽位适配器、统一费用账本、Q1 条件性回归测试。
2. **SOLVING（3–12 h）**：A 完成 Q2 因果预测与 walk-forward 小窗口；B 完成统一优化器、执行器、核算器与 Q3 单日 MPC 小算例；互查输入输出接口。
3. **SOLVING（12–22 h）**：Q2/Q3 全流程 + Q4 主价格口径；先抽样日验证再跑全年。
4. **MODEL_FREEZE（22–28 h）**：官方结果模板、全年约束/费用/信息时间戳审计、必做敏感性与最小消融 → 冻结模型与结果。
5. **PAPER（28–36 h 前段）**：集中写作与制图。
6. **FINAL_CHECK（最后）**：交叉复算与最终检查，不再增加模型。

**停止规则**：第 20 小时 Q1–Q3 未闭环 → 删除全部增强项、复杂预测器和非必要敏感性，只保留正确可验证的四问主线。不建议两人并行写两套优化内核——共享口径才是风险源。
