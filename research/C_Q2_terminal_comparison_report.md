# 第二问终端库存处理对照报告

## 目的

D007 规定：全年正式主模型必须在"每日回初值、滚动多日视野、终端库存价值"三者间做费用、可行率和 SOC 轨迹对照后再定，不得自行升格小窗口临时口径。本报告给出对照结果，供人类裁决全年正式口径。

## 实验设置

- 预测策略：固定为七天前同刻点预测（终端口径不应与保守程度选择耦合）。
- 终端候选：
  - `plan-eq`：每日计划首尾库存相等（`E144_plan = E0_plan`，三天探针的临时口径）；
  - `terminal-value-θ`：终端自由，对期末库存赋 θ 元/kWh 价值，θ ∈ {0, 0.4, 0.8, 1.2}；
  - `rolling-Nd`：N 天滚动视野，视野末回到起始库存，只执行第一天，N ∈ {3, 7}。
- 回放范围：2025-01-01 至 12-31；评价窗口 2025-02-01 至 12-31 共 334 天。
- 所有费用由独立核算器复算；全部配置不可行天数均为 0，核算全部通过。

机器结果：`experiments/q2_terminal_comparison_results.json`。

## 现象

1. **plan-eq 把库存钉死在上限。** 每天要求计划首尾库存相同，在光伏和低价时段会持续充满电池，导致 334 天日末库存全部等于 10800 kWh。电池失去跨日调节能力，正常购电费反而最高。三天探针里两套方案一月末都顶到 10800，正是这个机制在全年尺度上的放大。**该临时口径不能作为全年正式规则。**

2. **低终端价值把库存抽到下限。** θ=0 与 θ=0.4 下期末库存停在 1324 kWh，69 天日末触及 1200 kWh，是"逐日无终端价值耗空电池"的典型形态（方法地图失败模式 #4）。θ 太小时终端价值不足以阻止跨日透支。

3. **高终端价值又把库存顶回上限。** θ=1.2 相当于把期末库存估得很贵，167 天日末停在上限，费用最高。终端价值需要精细标定，且对 θ 敏感，不是稳健口径。

4. **滚动多日视野在费用和轨迹上同时最好。** rolling-3d/7d 总费用最低（约 1689 万），日末库存中位数约 8650 kWh，既不触上限也不触下限，跨日调节能力保留完整。滚动视野用"未来几天要回来"这个信息替代了对终端价值的人为定价，避免了 θ 标定问题。

5. **紧急购电占总费用约 28%**，是主导风险项；终端口径对它的影响约 1%（约 5 万 kWh），远小于预测质量和保守程度的影响。

## 结论与请求裁决

- 数据支持：**rolling（滚动多日视野）在费用、可行率和库存轨迹三项上同时最好**，且不依赖需要人为标定的终端价值参数。
- `plan-eq` 有明确病态（库存钉死上限），不建议作为全年正式规则。
- 正式口径必须由人类冻结后再跑全年；本报告不自行选定。

请人类裁决：全年正式采用哪一种终端库存处理口径？可选 rolling-3d / rolling-7d / 其他 N / 其它口径。

## 附：保守程度的初步对照（供参考，非本报告裁决项）

在 2 月至 4 月窗口、rolling-3d 下比较"预测方法 × 保守等级"：

| 七天前同刻/point | 3,723,914 | 599,785 | 159,240 |
| 同星期日衰减/0.7 | 3,904,288 | 907,724 | 235,917 |
| 同星期日衰减/0.8 | 4,004,029 | 1,005,629 | 259,266 |

| 七天前同刻/0.9 | 4,359,204 | 1,346,712 | 344,504 |

**点预测在所有候选里费用最低，分位保守反而更贵。** 原因是储能本身已经跨时段对冲了预测误差，在购电侧再加保守裕度属于重复对冲，只增加正常购电费。这与"报童临界分位 0.8"的直觉结论相反，也印证方法地图"0.8 只是候选、必须按实际总费用比较"的要求。该窗口仅 3 个月，正式选择还需按顺序选择方式在全年范围复核。
