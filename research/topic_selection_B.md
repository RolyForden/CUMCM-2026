# 1. 每道题的核心判断

## A 题：药材的烘干问题

**本质要求。** 建立圆柱药材内部热量和水分传递的空间—时间模型，从短时预热扩展到变参数全程干燥，找出“所有位置含水率低于 0.15”的停止时间，再加入实测尺寸收缩。题目核心是物理方程、边界条件和数值求解的一致性，不是拟合一条平均含水率曲线。

**初步路线。** 以轴对称、径向一维模型作为候选简化，明确忽略端面效应的依据；采用保守离散的传热、扩散模型和隐式时间推进。Q1 先处理固定热物性、含水率相关扩散系数和给定环境边界；Q2 接入温度、含水率相关物性；Q3 用空间最大含水率判定终止；Q4 再用归一化半径坐标或移动网格处理收缩。可以比较有限体积与有限差分、固定与变物性、固定几何与收缩几何，但不应另起互不相连的四套模型。

**最大优势。** 输入小，参数多数已给，四问形成自然递进；一旦基础求解器可信，结果表、剖面图、热图和收敛分析可以复用。没有必须接入外部服务的依赖。

**最大风险与拖死点。** Q4 收缩时坐标变换、物质守恒和干基含水率定义处理不一致，可能让 Q1—Q3 都已出图后仍无法完成整题。另一个风险是“稳定算出一个数”被误当成物理模型正确：环境湿度与药材干基含水率的边界通量口径、热湿耦合程度、端面效应都需要清楚论证。温度在经验扩散公式中必须使用 K，不能直接代入摄氏度。

**baseline 时间。** Q1 第一份经过边界、量纲、非负性和两级网格检查的 baseline 约 2—4 小时；Q1—Q3 可连接的可信版本约 5—8 小时；含 Q4 的完整基础版本约 8—14 小时。仅有平均值的集总模型可更快，但不能满足径向输出要求，不算整题 baseline。

| 维度 | 判断与理由 |
|---|---|
| 题意理解、领域依赖 | 中高；需理解圆柱坐标传递、初边值条件和变系数守恒形式，AI 可协助推导但需要人类复核 |
| 数据清晰与处理 | 数据量很小、读取快；温湿输入只到 4 h，后续 2—3 天如何延拓需提出并验证假设，不能默认为有全年程边界 |
| 子问题逻辑链 | 很强；同一求解框架逐步加入变物性、终止事件和收缩 |
| 量化与验证 | 网格收敛、时间步收敛、对称性、通量平衡和极限算例都可做；没有内部温湿实测，不能宣称通过真实干燥试验验证 |
| 数学深度与竞争路线 | 深度高，但物理约束使路线集中；不同离散法更多用于互证，不能把换求解器本身当创新 |
| 编程与调参 | 中高；主要成本在中心点、表面通量和收缩处理，不在大量超参数搜索；隐式算法可能降低步长调试成本 |
| 泄漏、评价失真 | 传统数据泄漏低；错误方程也可数值收敛。Q4 使用已给半径数据是题目输入，不能再称半径曲线为独立模型验证 |
| 敏感性、消融、稳健性 | 很丰富；传热/传质系数、环境延拓、网格、端面近似、几何收缩。比较 Q3/Q4 时物性公式也变化，不能把全部差异都归因于收缩 |
| 图表与论文叙事 | 很好；热湿时空图、径向剖面、最慢干燥点轨迹、收敛表可构成完整证据链 |
| Agent 并行 | 中；适合分成方程与单位审查、数值实现、独立验证/作图。Q4 依赖共同方程和接口，不能靠堆 Agent 消除串行瓶颈 |
| 两人分工 | 一人负责方程、假设和论文，一人负责求解与验证；必须交叉审查通量、坐标和量纲，不能完全互不接触 |
| 创新与上限 | 稳健停止时间、收缩与物性影响的分离、误差控制具有题目针对性；上限高，但经验公式固定，模型自由度小于表面观感 |

**一天半可行性：中等。** 如果前 4 小时能建立可信径向模型，后续可控；若一直纠缠边界定义，风险迅速上升。**模型表现一般能否写完整论文：可以，但须四问均有基本可信结果。** 没有实际观测误差指标不等于无证据，可以用数值验证和假设敏感性支撑；只有漂亮云图、没有守恒与收敛检查则不够。

## B 题：无线电干扰源的快速自动定位与清除

**本质要求。** 在源数、位置、接收半径和部分发射方向未知的环境中，使用带有界角度误差的主动观测，设计搜全、定位和清除的序贯决策。目标既有完整清除约束，又有移动、切台、检测与清除的综合时间成本。

**初步路线。** Q1 用角度可行域的半平面交与多边形顶点计算直径，区分直径和最小覆盖圆；例如等边三角形说明“以区域直径为直径的圆必能覆盖”并不普遍成立。Q2 比较可行域收缩与行走代价，不能只取两条理想射线的交点。Q3 先采用覆盖扫描、逐频道发现、保守定位及清除确认的策略；Q4 增加从不同方位检测和未发现区域的覆盖保证。改善方向是信息收益与行动成本平衡，不建议从强化学习训练起步。

**最大优势。** 官方模拟器提供直接的任务反馈，数学几何、搜索策略、路径成本和实验叙事连贯；同一策略在多种环境中的失败原因容易可视化。

**最大风险与拖死点。** 不知道源总数，遇到 `no_signal` 不能区分无源、超距和背向，Q4 的“搜全并有理由停止”最容易失控。达到 10 个清除目标不能证明全部清除。若覆盖证书不足，平均每个源时间很短也可能只是遗漏难找源。外围源朝外辐射时可能需要到目标圆域外检测，题目允许这样做。

**baseline 时间。** Q1/Q2 几何原型约 1—2 小时；模拟器已可登录的前提下，Q3 可清除部分源的程序约 3—5 小时，含完整性检查的可信 baseline 约 6—10 小时；Q4 全流程约 10—16 小时。当前仅核验说明文档，未验证模拟器安装、账号或服务可用，接入等待不能计为已解决。

| 维度 | 判断与理由 |
|---|---|
| 题意理解、领域依赖 | 中高；无线电物理已简化，真正难点是部分可观测、角度几何及停止判据 |
| 数据与处理 | 不提供可直接读取的真值，靠交互获得观测；所有演练和正式测试依赖联网、账号和服务器时间校验 |
| 子问题逻辑链 | 强；几何定位 → 选点 → 全向源搜索 → 定向源搜索 |
| 量化与验证 | 演练结束可得源总数，可以算清除率；正式测试不显示总数，不能虚构其清除率。正式案例随机，每问仅三次，无法当大样本统计 |
| 数学深度与多路线 | 高；覆盖几何、鲁棒定位、主动感知、路径规划可竞争；同时展开全部方向会失焦 |
| 编程与调参 | 高；需可靠状态机、串行 HTTP、重试幂等、超时处理、退化交会修复；搜索步距、选点和退出阈值相互作用 |
| 泄漏、评价失真 | 自建模拟器不能暗用源真值；同一地点误差固定，重复测量不能当独立采样降噪；只报成功案例会高估效果 |
| 敏感性、消融、稳健性 | 可以对源数、半径、方位、角度误差和策略部件做对比；配对实验需要可复现自建案例，但只能作为补充，不能替代官方日志 |
| 图表与论文叙事 | 很好；搜索轨迹、可行域收缩、耗时分解和清除率分布有解释力 |

| 创新与上限 | 较高；覆盖保证与低成本发现结合、失败后自适应补扫、带误差的清除证书比复杂模型更有价值 |

正式测试 Q3、Q4 各三次，每次有 25 分钟窗口且进入后最多运行 20 分钟；仿真时间与现实时间不同，检测虚拟耗时 5 秒不要求现实等待 5 秒。按题面/附件，2026-09-13 17:30 后不能启动新测试，建议 15:30 前完成正式测试。本分析没有消耗测试机会。

**一天半可行性：偏低至中等，波动最大。模型一般能否写完整论文：有条件可以。** 必须完成六次正式测试及日志、报告演练清除率和失败原因；如果只做出前两问和局部成功轨迹，就缺少整题最关键证据。

## C 题：微网与外部电网电力调控策略

**本质要求。** 在储能容量、功率、效率和不同购电结算机制约束下，把日前预测、实际执行、预报更新和实时电价连接成可回放的决策流程。最终要证明策略在给定信息条件下可执行、费用可核对，不能用全年实际数据倒推一个看似完美的购电计划。

**初步路线。** Q1 用十分钟分辨率的线性规划建立储能调度 baseline，并保留无储能直接购电对照。Q2 用仅依赖过去信息的负载/光伏简单预测生成日前计划，在实际数据回放时核算紧急购电。Q3 在指定预报发布时刻重新规划未执行时段，统一计算计划、增购、减购违约及紧急购电费用。Q4 加入电价信息约束，复用同一执行和核算器。基于历史误差分位数的安全余量、情景优化和有限滚动优化是可比较方向；先避免过多预测器与优化器交叉组合。

**最大优势。** 官方数据已核实齐全，基本约束较简单，单日仅 144 个时段。简单 baseline 到改进策略之间存在清楚的对照关系，费用、紧急购电和约束违反可量化；即使先进方法不胜出，也能解释更新预报何时不值得其交易代价。

**最大风险与拖死点。** 不是求解器速度，而是构建了使用未来真实数据的调度器，直到写作时才发现无效。跨日储电量、时间标签、计划与实际分离、调整价如何结算若不统一，四问结果无法公平比较。尤其 Q4 未明确全天波动电价在 0:00 是否已知，必须把“预知价格”和“仅历史可用”分开，不能自行默认前者。

**baseline 时间。** Q1 含独立能量/费用检查约 1—2 小时；Q2 数日无泄漏回放约 3—5 小时；复用接口连接 Q3/Q4 的基础版本约 6—10 小时。十分钟级全年回放的实际耗时尚未测试；不能仅凭单日规模宣称全部实验已可快速完成。

| 敏感性、消融、稳健性 | 很强；预报更新有无、安全余量有无、容量/功率/效率变化、预测误差及违约价格变化都能形成题目相关证据 |
| 图表与论文叙事 | 很强；典型日功率与储电量、全年费用分布、费用瀑布图、紧急购电热图和更新收益图可以直接连接四问 |
| Agent 并行 | 高；数据/时序审查、优化器、独立执行核算器、实验与图表可明确分工，前提是统一状态和费用接口 |
| 两人分工 | 一人负责数据、信息可用时刻与验证，一人负责调度模型和实验；两人共同确认费用公式，论文随已核验结果推进 |
| 创新与上限 | 高；用预测误差指导备电、把预报改善与调整成本连接、设计稳健储电终端条件，均比堆模型更有针对性 |

需要特别管理的四个口径：① kW 与十分钟 kWh 的换算；② 90% 是分别充放电效率还是整体往返效率，须明确解释并评估影响；③ Q1 明确日初日末电量相同，但不能无依据给 Q2—Q4 每天重置电量；④ 下调费用如何与已付计划电费衔接，要据题意写出透明算例，不能在不同策略间使用不同记账法。

全年输入从 1 月开始而输出主要从 2 月开始，1 月可作为初始历史窗口，但“1 月训练、之后如何更新”是建模方案，不是题目自动保证的最优切分。跨日 SOC 需从题设 1 月 1 日初值一致推进，或明确给出可审查的初始化方案。全知实际值优化只能作为理想下界，不能标作可执行策略。

**一天半可行性：中高，三道本科题中最稳。模型一般能否写完整论文：可以。** 保留一个可执行简单策略，诚实说明复杂改进收益不稳定，仍能用连续时间回放、成本分解、约束检查和分季节稳健性构成完整论文。条件是不能缺失后两问的基本策略和统一核算。

## D 题：时频冲突检测与消解（本队不纳入可选排名）

**本质要求。** 将重复出现的时间—频段矩形安排成无冲突资源计划，尽量少撤销、少调整并保持高优先级装备；之后评估新增容量和放宽间隔调整的收益。

**初步路线。** Q1 构造所有重复占用区间并建立冲突图；Q2 从优先级贪心与有限候选平移开始，再用整数规划/约束规划或局部改进；Q3 在固定 Q2 计划和固定资源时间窗下安排新增 C 类；Q4 加入可选间隔平移。一个计划只能改一个参数的约束必须贯穿所有候选生成，不能同时平移时间和频率。

**最大优势。** 150 条计划很小，冲突判据完全可计算，独立检查器容易做。官方数据中同类占用模式一致：A 类宽 10、长 5、间隔 60、3 次；B 类宽 15、长 3、间隔 40、4 次；C 类宽 3、长 2、间隔 8、12 次。

**最大风险与拖死点。** Q3 的时间资源范围和新增 C 类需求必须明确。题面说不增加时频资源，却未直接给出一个全局时间窗数值；若允许无限推迟新增任务，最大安排数量问题会失去原本意义。可以提出沿用原任务时间包络的解释，但需要说明，不能暗中选一个有利范围。追求“证明全局最多”也可能耗尽时间。

**baseline 时间。** Q1 冲突表约 0.5—1 小时；Q2 经独立冲突复查的贪心方案约 1—2 小时；四问基础链约 4—7 小时，前提是 Q3 口径已明确。全局最优证明时间无法保证。

| 维度 | 判断与理由 |
|---|---|
| 理解、领域依赖、数据处理 | 低到中；无需额外电磁学知识，半开区间边界和重复周期定义必须精确 |
| 逻辑链、数学深度与路线 | 链条强；冲突图、候选方案选择、装箱与局部搜索都有空间，但 Q3 继承 Q2 的选择，不应独立重做一个更方便的初始计划 |
| 编程、调参 | 中；贪心快，精确最优较难。多目标优先顺序比调搜索参数更关键；任意权重和可能掩盖撤销高优先级计划的代价 |
| 验证与评价风险 | 可行性验证很强；最优性验证需上下界或求解器界。重复间隔是上次结束到下次开始的空档，不能误当开始到开始周期 |
| 敏感性、消融、图表与写作 | 好；调整上限/间隔放宽、优先级规则对比，时频占用图和冲突网络可形成清楚叙事 |
| Agent 与两人分工 | 很好；候选生成、独立冲突检查、优化、可视化分离；一人优化、一人验证和论文，集成负担较低 |
| 创新与上限 | 中高；结构化候选压缩、词典序目标、容量上下界比换元启发式名称更有价值 |

**一天半技术可行性：高，但不作为已确认本科组的选项。模型一般能否成文：可以，** 报告可行解及已知上下界即可诚实表述，但未证最优不能写“最多”。即使技术得分较高，不能越过队伍可选范围替代 A/B/C。

## E 题：SEM 广告投放策略（本队不纳入可选排名）

**本质要求。** 从不同粒度的投放记录评价效益、划分关键词类型，并据此选择关键词、分配预算和给出跨年度不确定性下的逐日策略。难点是从观测描述走向有依据的干预预测。

**初步路线。** Q1 做分层描述统计、时间变化和带控制变量的关联分析；Q2 对成本与可观察效益采用明确阈值/稳健归一化，给出分类稳定性；Q3 用可解释效益代理量及预算约束形成情景分配；Q4 扩展为区间/情景稳健方案。若只观测年度关键词汇总，就不把它包装为已识别的逐日竞价响应函数。

**最大优势。** 前两问统计分析快，图表丰富；如果接受代理效益和明确情景假设，可以形成易读的业务解释。

**最大风险与拖死点。** 想从年度汇总推导每个关键词每天“出价—展现位—点击—注册”的因果链。官方原包虽补齐三表，仍没有逐日关键词、真实出价、广告创意文本、关键词级注册归因及充分预算信息。无成本不代表无潜在价值，年度最大编号不代表样本数量；大量 Agent 都无法从无观测处恢复可验证真值。

**baseline 时间。** Q1 描述性统计约 0.5—1 小时；Q1/Q2 基于已观测代理效益的可复核分析约 1—3 小时。Q3/Q4 可在 4—8 小时生成条件情景方案，但**仅靠现有数据建立真实干预效果可验证的全题 baseline，没有可靠时间承诺**。

| 维度 | 判断与理由 |
|---|---|
| 理解与领域依赖 | 表面低、实质高；需要区分流量、互动、注册、收益，以及平均点击成本和真实竞价，不能混用 |
| 数据清晰与可处理性 | 表格小且可连接，但粒度不一致；关键词是数值标识，不能进行有依据的文本语义关联或创意质量分析 |
| 子问题逻辑链 | 叙事连贯，但 Q2 分类到 Q3 最优分配的响应机制缺观测支撑，Q4 跨年进一步增加假设 |
| 数学深度与路线 | 可做分层回归、稳健分类、预算优化和区间预测；能写出很多模型不代表参数可识别 |
| 编程与调参 | 描述统计低，完整预测优化中高；主要成本在指标定义和假设校准，不是程序运行 |
| 验证、泄漏和失真 | 风险最高；用全年关键词统计再回测同年 2 月，会构成事后信息使用。可按题意做历史重构，但不能称真实前瞻验证；总注册数也不可全部当广告增量 |

| 图表与论文叙事 | 可出消费—效益散点、时间图、单元比较；外观容易完整，证据到策略的连接较弱 |
| Agent 与两人分工 | 数据统计、分类、情景分析可并行，但共同的效益口径和识别缺口是瓶颈；两人需集中解决指标定义，不能各自设计评分再拼合 |
| 创新与上限 | 诚实处理不可识别性、分层收缩和稳健预算有价值；给定资料下可验证上限受限，复杂预测模型不会自动提高上限 |

**一天半技术可行性：描述分析高，高质量全题结果偏低。模型一般能否成文：有条件，且证据薄弱风险大。** 可以写成透明的情景决策论文，但如果要求强证据支持逐词逐日最优投放，现有数据不够。另因本队为本科组，不纳入最终备选。

# 3. 排名

## 第一选择：C 题

在官方数据恢复可用后，C 最有希望在一天半内完成“可执行 baseline—单一明确改进—完整回放—敏感性与论文”的闭环。它同时具备小规模优化、全年验证样本、自然的四问衔接和可拆开的 Agent 工作。其优势不在电力主题，而在**可用过去信息制定计划，再用未参与决策的真实值核算结果**这一可验证结构。

首选是有门槛的：完成下面的时序与核算探针；明确效率、结算和电价可知性。若探针失败，不能因为已经写了优化器就坚持 C。

## 第二选择：A 题

A 适合作为数据与外部服务依赖较少的后备。输入小、四问递进、图表和数值证据好组织。在 C 的信息口径迟迟无法统一，而 A 的基础 PDE 与边界检查通过时，A 可以更稳。

将 A 排第二而非第一，是因为径向求解与收缩处理是串行关键路径，且缺乏药材内部实测验证。AI 可以快速给出代码，但其方程与边界是否正确必须人工识别。

## 本科组不建议优先选择：B 题

不是 B 缺乏建模价值，而是在两人、一天半限制下，Q4 搜全保证、接口可靠性和正式测试交付同时构成风险。若先解决了模拟器接入和有界时间的覆盖完成策略，其位置可上升；当前没有这些实测证据。

**D、E 不参与本队可选排名。** 如果只作技术比较，D 的落地性很有竞争力；这不能改变本队已确认的本科组约束。E 即便允许选择，也因可验证干预链不足不建议优先投入。

# 4. 反向论证

## 假设选择 C 是错误决定

以下不是泛泛列缺点，而是可以推翻首选的具体条件：

1. **信息集不能自洽。** 无法明确 Q2 的当日负载/光伏哪些已知，或 Q4 在 0:00 可知哪些电价；各人分别使用了不同先验。如果不预知真实值就无法产生有意义的策略优势，应撤回“C 验证优势明显”的判断，而不是偷偷使用真值。
2. **独立核算不一致。** 对同一小算例，优化器和独立执行器得到不同的储电量或费用，尤其下调购电、紧急购电和跨日终端处理发生重复收费/漏计。如果一个限时探针后仍无法定位原因，C 的快速 baseline 优势不成立。
3. **模板时间歧义牵连所有结果。** 官方模板与正文覆盖时段不一致，十分钟错移影响负载、太阳能和价差；若无法形成统一映射和提交解释，生成全年结果只会扩大错误。
4. **滚动调整的实际收益太小且解释不稳。** 更新预报带来的误差改善不足以覆盖调整成本，各合理费用解释下排序大幅变化。如果能诚实写成“何时不调整”的结论仍可成文；但若同时连基本费用账本也不稳定，就应换题。
5. **工作范围膨胀。** 同时训练多个预测器、优化多个风险参数、全年度频繁重算，导致后两问和论文无时间完成。若前半天仍只有 Q1 最优值，没有 Q2 闭环，应主动降低模型复杂度；仍不能贯通则转向已通过探针的 A。

此外，官网原包已找到并实读，并不等于项目已完成数据版本替换和可复现输入管理；后续继续读取本地缺表版本会直接破坏上述依据。

## 什么情况下 A 应超过 C

- A 探针在 45 分钟内证明圆柱扩散离散和边界处理可行，两人能独立解释中心、表面及单位，且对长时环境延拓有清楚方案；C 探针却连时间和费用账本都无法统一。
- 两名成员中至少一人确实能审查传热传质与移动坐标推导；这是后续确认的能力条件，当前不能假设已有。
- A 的简化边界、长时延拓和收缩处理在合理选择下给出稳定结论，而 C 对费用含义或价格信息假设高度敏感。
- 可用比赛时间进一步缩短，团队已拥有经过核验的 A 求解基础，但尚没有 C 的逐时执行核算器。这里强调“已核验”，不是代码行数或出图数量。

# 5. 快速探针建议

下面是**建议而非已经执行的实验**。每题最多 45 分钟，两名成员可各负责一题，但只检查可行性，不提前全面求解。45 分钟到点保存成功/失败和障碍说明，不以“再调一点”无限延长。阈值是用于筛选工程路线的预设标准，不是竞赛官方评分要求。

## C 题探针：时序输入与独立账本能否闭合（45 分钟）

**输入。** 官网附件 1；附件 2 中 1 月历史及 2 月 1—2 日负载、光伏真值；附件 3 中对应发布时刻的预报；附件 4 中相同日期电价；储能参数；官方 result1 时间标签。只取小窗口，不跑全年。

**操作与时间盒。**

1. 0—10 分钟：生成两天各 144 个时段的输入表，区分记录时刻、交付时段、预报发布时间和目标时间。检查 0:00、24:00、跨日预报和模板错移，输出一张映射表。为未确定口径标注两种解释，而不是悄悄选择。
2. 10—20 分钟：Q1 无储能直接购电作为对照；尝试一个单日储能 LP。暂用明确注明的单程效率解释，按 kWh 记账。用几个时段的手算检查储能变化、功率限额和终端条件。
3. 20—32 分钟：用前一天同一时段或此前历史均值制定 2 月 1 日计划；在实际负载/光伏上顺序执行，缺口紧急购电。策略函数不读取未来实际值。保留真实 SOC，不隔日重置。
4. 32—40 分钟：用独立函数重算能量平衡和费用；增加一个小型增购/减购手算例，检查 Q3 核算是否可扩展。比较“有 6:00 更新”和“仍用 0:00 预报”的数据可用性，不追求优化收益。
5. 40—45 分钟：保存可行性结论、各环节耗时、所有未决口径；据单日耗时保守估计全年代价。

**成功标准。** 正确读出每日至少 144 个不重不漏的时段，能恢复并区分实际光伏与预报；优化器能返回可行解，独立重算的 SOC、功率和能量残差在预设浮点容差内（如每步 10^-5 kWh 的能量容差）；两种费用计算差异小于 0.01 元；策略只依赖允许的信息；遇到预测不足时确实产生紧急购电并计入费用。允许 LP 并不显著优于简单策略，探针成功不以节省百分比为条件。

**失败标准。** 30 分钟仍不能对齐时间或区分预测与真值；必须使用当天实际值才能生成策略；储能或费用核算出现无法解释的差异；求解失败无法定位约束；四问的信息/结算解释明显不一致。若唯一未决点只是提交模板标签，可记为“条件通过”，但必须列为拍板前待定项。

**判断最大障碍是否真实。** 若 LP 很快而账本不闭合，说明风险确在信息与结算，不能继续加模型掩盖；若账本闭合且单位检查通过，C 的主要工程风险已有直接缓解证据。

## A 题探针：固定几何基础求解是否可信（45 分钟）

**输入。** Q1 几何、初值及附录参数；官方附件 1 的前 1800 s；附件 2 仅用于确认未来收缩范围；题面附录 3、4 的公式只核对量纲，不完成后两问。

**操作与时间盒。**

1. 0—8 分钟：写出径向热量/水分方程、中心对称条件和表面通量条件，明确每个参数单位与含水率口径。记录忽略端面、蒸发潜热处理等候选假设，未确认部分不得表述成题目事实。
2. 8—25 分钟：建立短时固定半径隐式离散，优先有限体积以处理圆心；先在常系数、均匀边界等简化核验例上运行，再代入 Q1 的含水率相关扩散系数，计算到 1800 s。
3. 25—37 分钟：用两级径向网格（例如 21/41 节点）和一次时间容差收紧比较；检查温度范围、含水率非负、中心对称、表面通量符号及离散平衡。
4. 37—45 分钟：保存一张径向曲线和收敛对照，列出从固定半径扩展到实测收缩时新增的坐标/守恒项，以及 4 h 后环境边界如何延拓的待决问题。

**成功标准。** 能在时限内跑通短时模型；不存在负含水率、异常温度或反号通量；两级网格关键点差异达到初筛标准（例如温度小于 0.5°C、含水率小于 0.01 kg/kg，并随细化有合理趋势）；有可解释的离散通量平衡，简单极限例通过。该阈值只表示值得继续，不足以保证四位小数输出精度。

**失败标准。** 方程、表面传质口径两人无法解释一致；只靠裁剪负值或任意平滑才能稳定；网格细化使结果显著漂移且无解释；仍不能处理 r=0；对收缩只计划“把半径替换进原代码”而没有守恒处理思路。若 45 分钟内只完成方程核验、未完成数值检查，结论为“未通过，工程速度不明”，不能写成已成功。

**判断最大障碍是否真实。** 探针只能验证基础 PDE 实现能力，**不能证明 Q4 已解决**。若基础部分就无法核验，一天半选择 A 的时间风险很高；若基础通过但收缩处理仍不清楚，A 仍只能作为条件备选。

# 6. 最终建议

- **首选：C 题，微网与外部电网电力调控策略。** 以通过时序与独立核算探针为条件。
- **次选：A 题，药材的烘干问题。** 以基础径向模型通过核验，并具备可说明的收缩处理路线为条件。
- **最大不确定性：** C 的信息可用时刻、购电结算及时间模板口径能否快速统一；A 的边界物理解释与收缩守恒能否在剩余时间内可信实现。
- **最终拍板前需验证：** 使用官网原始完整附件；执行上述两个限时探针；由两名人类成员确认关键口径、接受的简化和剩余时间安排，再决定最终题目。当前保持 TOPIC_SELECTION。
