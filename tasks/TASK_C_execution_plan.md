## 阶段 0：数据落仓与哈希（~0.5h，B）

- 验收：MANIFEST 完整；读取器只读 `data/raw/`，不触碰原始目录。

## 阶段 1：144 槽位适配器 + 统一长表（~1h，A）

- `src/data/slot_adapter.py`：输入列 → 槽位 0-143 → 模板列，起点对齐（D002 P0-1），四问共用，禁止字符串拼接。
- 长表：`decision_time, valid_time, date, slot, price, load_actual, pv_actual, pv_forecast, forecast_issue, lead_hour`；附件 3 日期列前向填充，跨日预报不截断（D002 P1-2）。
- 输出 `data/processed/long_table.parquet` + 构建日志。
- 验收：每天恰 144 点；跨日标签不丢失；无 NaN；与原始逐值抽查一致；附件 3 issue/valid 对齐无误。

## 阶段 2：探针内核 + 小窗口闭环（~2h，B 主 A 核）

- `src/core/lp_kernel.py`：统一 LP（scipy.optimize.linprog，HiGHS dual simplex + IPM 双引擎对拍），字典序吞吐最小化；母线侧能量平衡、SOC ∈ [1200,10800]、c/d ≤ 833.33 kWh/格、弃光 w ≥ 0、g ≥ 0。
- `src/core/executor.py` + `src/core/accountant.py`：独立执行器与核算器（与优化器不共享代码路径），账本 = 正常 + 紧急 + 上调 + 下调（D002 P0-8 替代价式）。
- 探针：3–4 时段窗口，**必含跨日案例 23:30–0:10+1**；规则法对照。
- 验收（四条全绿才算过）：能量残差 < 1e-9；SOC 全程合法；无同时充放电；规则法 ≥ LP；**优化器目标值 == 核算器复算值**；跨日边界正确。
- 报告：`experiments/probe_timing.md`（参数、求解器、残差、结论）。

## 阶段 4：Q2 因果 walk-forward（~5h，A）
