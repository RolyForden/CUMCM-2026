# C 题 30–45 分钟时序与独立核算探针

- 授权：2026-09-12 人类确认 13 项 P0/P1/P2 口径（见 DECISIONS.md D002），授权执行小窗口探针。探针通过前**不得**运行全年数据（硬闸门）。
- 输入：`DECISIONS.md` D002（冻结口径）；`research/C_method_map.md` §1.2/§14；`research/C_problem_map.md`；官方数据包与替补数据源（见 D002"数据源核实"）。
- 目标：用 3–4 个十分钟时段（30–45 分钟窗口）闭环验证"时序映射 + 能量账本"，再跑 Q1 全日回归锚点。窗口刻意取小：单位、标签、效率、SOC 连续性错误在 3 个时段内就会暴露。
- 输出：`src/` 下的槽位适配器、最小 LP 内核、独立核算器与探针脚本；`experiments/` 下的探针报告（参数、求解器、残差、结论，符合 AGENTS.md 第 9 条）。
- 验收（探针通过标准，任何一项不过 → 修 → 重跑直到全绿）：
  1. 小窗口：能量残差 < 数值容差（~1e-9）；SOC 全程在 [1200, 10800]；无同时充放电；规则法成本 ≥ LP 成本；优化器目标值 == 核算器复算值（核算器与优化器不共享代码路径）。
  2. 小窗口至少含一个跨日边界案例（23:30–0:10+1），专门考验 0:00+1 标签与槽位适配器。
  3. Q1 全日回归锚点：冻结口径下复现 35126.948589 元，能量平衡最大残差 ~1e-13（dual simplex 与 IPM 双引擎对拍）。
  4. 弃光不能吸收购电（TASK_C_probe_model_corrections.md §6.1/6.2）：光伏为 0 时弃光路径结构上关闭；松弛解靠同时充放电制造假出口时必须被审计器拒绝。
  5. 单槽位脉冲测试（§6.3）：首/中/尾三槽只放负荷，购电与费用必须落在同一 slot_id——必须能识别整体平移一格，不能只检查全天费用。
  6. 模板回读测试（§6.4）：写 result1 后重新读取，144 槽逐列数值与区间标签完全一致；错位标签必须报错，禁止时间字符串模糊匹配。
- 边界：不改 `data/raw/`（原始官方包只读，处理结果写 `data/processed/`）；不碰全年回测；不引入外部数据集；探针报告不含未来信息使用。
- 完成标准：探针报告全绿 + 更新 `SESSION_HANDOFF.md`。
